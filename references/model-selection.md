# 模型选型：S1 由用户意向 + 推荐共同决定

> **v3.6 / v5.2 适用范围**：默认角色资产是**每位角色 1 张 `ROLE_SHEET_X` 上下分区定妆板**（上 1/3 正侧面面部特写 + 下 2/3 放大裁头正面服装图与背面全身，出图提示词逐字采用用户定稿），前两格来源按输入模式（`M0 零素材` 默认 / `M1 部分` / `M2 已有`）决定，见 `references/input-modes.md`。下面凡提到「面部四宫格 / 六类实例 / 13 项验收」的地方，都只适用于**用户主动要求的扩展定妆包**；默认项目改为拼板 8 项验收。本文件涉及角色参考包的具体表述以 `character-sheet-spec.md` 附录 A 为准。
>
> **v3.3 扩展定妆包变更**：第一张图必须是 `FACE_QUAD_01` 面部特写四宫格（同一图四等分：正 / 左 90° / 右 90° / 背 180°，全为头部特写），后面每张定妆图按 `character-sheet-spec.md` §4.4 对应性矩阵指回它；全包统一纯色暖灰 `#C6BCB1` + 三点式 5500K 中性光 + 105mm（头）/85mm+（身）+ 低密度 Tiffen 黑柔 + 无现代浓妆；另产朝向三视图、四格定妆板与六张单图，定妆包验收 13 项。出图前先过 `character-design-aesthetics.md` 设计自检 6 问与 `costume-design.md` 服装自检 6 问。本文件涉及角色参考包的具体表述以 `character-sheet-spec.md` 为准。

> 本阶段发生在**总揽确认之后**。能力数字与来源见 `references/model-profiles.md` / `assets/model_profiles.json`（检索 2026-11-05，以平台当日为准）。
> 先问用户意向，再给推荐；不自己拍板，不把 `deprecated` 模型放进推荐。

## 1. S1 必须问的三件事

1. **意向图像模型**：定妆/定景/色卡/标准首帧打算用哪个？（Nano Banana 2 / GPT Image 2 / Seedream 5 / Midjourney / FLUX / SDXL…）
   → 若用户给了多个图像模型，追问一句：**是否按「定基调 / 出人物 / 锁一致性」分工**（见 4.1 三段接力分工法）；若用户只给一个，不强行拆成多模型。
2. **意向视频模型**：动态镜头打算用哪个？（Seedance 2.0/2.5 / Kling 3.0/4.0 / Veo 3.1 / Runway / Wan / 海螺…）
3. **生产条件**：可用平台与地区、是否需要本地/开源、预算是否按秒计费、生成通道 A/B/C。

同时给出**主推组合 + 备选 1–2 个 + 理由 + 两层硬约束表**，并说明该组合对整体规划的初步影响。

## 2. 三层生产链

| 层 | 任务 | 产出 | 选型关键能力 |
|---|---|---|---|
| ① 定妆 / 定景（图像模型） | 文生图 + 多图参考 / 对话式改图 | **默认：每人 1 张 `ROLE_SHEET_X` 上下分区定妆板**（+ 零素材时从零生成 `FACE_CLOSE_X` / `OUTFIT_X` / `ROLE_STILL_X`）；扩展包才做定妆基准 + 朝向三视图 + 四格板 + 六张单图；另出色卡、场景空镜、标准首帧 | 角色一致性、参考图上限、局部重绘、色卡可控、**多朝向与多距离稳定** |
| ② 动态（视频模型） | 图生视频（首帧 / 首尾帧 / 多图参考） | 一条条生成条，内含 2–4 秒成片镜头 | 跨镜身份保持、半透明材质、克制运镜、浅景深、**单次时长上限** |
| ③ 统一 | 剪辑 + 调色 + 音效 | 成片 | 统一 LUT、柔光/光晕、黑位与高光控制 |

**关键判断**：色场一致性不靠模型，靠 ① 的标准首帧 + ③ 的统一调色。把「颜色不统一」归因于模型并反复换模型，是最常见的成本浪费。

## 3. 选型决策树（按顺序，前项优先）

1. **同一角色是否跨 10 镜以上？**（本类短片几乎总是「是」）
   → 图像层必须选多图参考 / 可锁角色的模型，先做**每人 1 张 `ROLE_SHEET_X` 上下分区定妆板**；视频层必须支持首帧或多图参考。**零素材时先按 `input-modes.md` 从零生成面部 / 服装 / 定妆照，不能因为用户没图就跳过这层直接文生视频**。缺少最终拼板时换任何模型都会换脸，只有一张正面半身图则转身与全身镜必崩，只有远景全身没有面部特写则近景五官崩坏。扩展定妆包（面部四宫格 + 六类实例）只在用户主动要求时启用。
2. **视频模型单次时长上限是多少？**
   → 这决定**生成条数**与跨生成跳色风险：8s（Veo）→ 5 条以上、最脆弱；15s（Seedance 2.0 / Kling 3.0）→ 3 条；30s（Seedance 2.5 / Wan 3.0 / Kling 4.0 verify）→ 2 条。上限越长，越要把时间码写细，而不是把镜头拉长。
3. **主体是否含水面、薄纱、雾、逆光水花、扬撒颗粒？**
   → 优先物理模拟与半透明表现稳的模型，且**必须**跑小样；这类材质是崩坏高发区。
4. **是否要求克制运镜 + 柔焦散景 + 中浅景深？**
   → 显式写「静态机位 / 仅极轻微推进」，并按模型机制禁运镜（Runway 只能正向描述）。
5. **负向词机制**：是否有独立字段、是否禁 `no/don't`、是否完全不支持。这直接决定提示词形态，见 `model-adapter.md` 规则 9。
6. **原生音频**：本片无对白，环境音与音乐后期加；**不作为选型依据**，带音频的模型反而要显式写禁对白。
7. **访问与预算**：国内可用性、按秒计费、是否需要本地自控；先 720p 小样，成片再升分辨率。

### 4.1 多图像模型三段接力分工法（v3.4，可选）

> 适用前提：用户给了 **≥2 个图像模型**，或明确说「一个定基调、一个出人物、一个保一致」。用户只给一个模型时不拆，按单一模型全包。
> 三个模型不是各分一块资产，而是**同一批资产的三道工序**。判据只有三条，按资产的第一属性归类。

| 模型角色 | 判据 | 典型资产 |
|---|---|---|
| **定基调**（Midjourney 类） | 美感要求高、**不要求**跨图同一人 / 同一场景精确复现 | 视觉母版、场景图、服装基调、质感探索板 |
| **出人物**（Seedream 类） | 人脸 / 人物资产 / 中国风；该范围内的一致性改图也归它 | 面部四宫格、面部单图、人物局部修正、故事板九宫格 |
| **锁一致性**（Nano Banana 类） | 要参考生成三视图、场景正反打、多图同传、跨镜不串脸不跳色 | 朝向三视图、四格板、服装放大、场景正反打、标准首帧 |

**接力链（顺序不可跳步）**：

```
定基调 ──参考素材按归纳 meta 指令分析 + 分组检查，写成 12 HEX 成品出图提示词──> COLOR_CARD_01（仅视频用）
   │                      │
   ▼                      ▼
出人物（人脸 / 中国风）──> 锁一致性（三视图 / 正反打 / 标准首帧）──> 视频层
```

**三处必然冲突与解法**（不解决就会要么跳色、要么串脸）：

| 冲突 | 解法 |
|---|---|
| 视觉母版想用单体美感模型，但标准首帧要 ≥6 张参考同传 | 拆成两张：`VISUAL_MASTER_01`（基调模型出，定调）与 `STANDARD_FRAME_01`（多图参考模型出，同传合成）。母版以**风格参考图**身份进入合成，不要求它自己装下所有参考 |
| 场景图归美感模型，但 6 个场景要跨镜不跳色 | 基调模型出 `SCENE_REF_0X` **基调版**（**同传色卡取色彩方案（A00 母版 / 首帧 / 人物资产除外）**，靠正文写死色值与光位 + 固定 `--seed`）；多图参考模型以它为参考出 `SCENE_REVERSE_0X` **一致性版 / 正反打**，后者才作为镜头首帧上传。色卡由参考素材**按归纳 meta 指令独立归纳 + 写死 12 个 HEX 成成品出图提示词**得出（有参考片帧时不依赖这批基调版），在 A 段场景图（取色彩方案）与 C 段视频【参考绑定】两处使用 |
| 服装归美感模型，但要与角色资产逐项对得上 | 基调模型只出 `OUTFIT_MOOD` 面料光泽与配色方向；`ROLE_OUTFIT_DETAIL` 由多图参考模型挂角色参考图出，进定妆包 13 项验收。基调模型服装图不作身份依据 |

**四条边界**：

1. **基调模型的原图不直接进视频上传序列**。上传序列只放色卡（仅【参考绑定】）、标准首帧、场景反打（可选）与人物两类参考；混入基调图会把它的柔焦与光晕带成「同一道光」。
2. **定基调不等于放飞色场**：`A00` 视觉母版不挂色卡；`A01–A0N` 场景基调图**同传 `@COLOR_CARD_01` 只取色彩方案**，靠正文逐项写死色值、占比方向、光位与同一组平台设置，全阶段 `--sref` 一律不写；三条铁律（尺度机位 / 光与皮肤 / 色场覆盖）不因换模型放松。
3. **色卡是 12 色归纳的色值数据卡，不是美感生图任务，也不是场景图的风格参考**：把视觉母版 + 全部场景基调图一起交给分析型图像模型，归纳 4 主 / 4 辅 / 2 强调 / 1 高光 / 1 阴影共约 12 色，每色只标 HEX 与用途；**在 A 段场景图（取色彩方案）与 C 段视频【参考绑定】两处使用**，A 段场景图同传色卡取色彩方案；A00 母版 / 标准首帧 / 人物资产不挂色卡，全阶段不写 `--sref`。占比由色场方案与摄影母版写死，不从色卡取色；定稿后全片共用一张。见 `color-system.md` §7。
4. **一致性不稳不靠 reroll 硬救**：跨镜跳色或串脸时，整包一致性主责交回多图参考模型，不回基调模型反复抽卡。`verify` 模型的小样不通过时，走「人物模型出基调版 + 一致性模型锁定」降级，并回 S1 让用户确认。

### 4.2 三段接力按输入模式调整（v3.6）

> 默认 `M0 零素材`：用户一张图都没有。三段接力不能只写「场景归 MJ、三视图归 NB」，必须补上**人物从零生成**这一段，否则链断在第一步。完整判定见 `references/input-modes.md`。

| 模式 | 定基调（Midjourney 类） | 出人物（Seedream 类） | 锁一致（Nano Banana 类） | 每人生成张数 |
|---|---|---|---|---|
| `M0 零素材`（默认） | `VISUAL_MASTER_01` + `CHARACTER_MOOD_X`（脸型气质、妆造、面料与配色方向，不上传）+ 场景基调版 | **`FACE_CLOSE_X` + `OUTFIT_X` + `ROLE_STILL_X` 全部从零生成**；身份锚是 S0 的 12 项 `ROLE_CHARTER_X` 文字设定 | `ROLE_SHEET_X`（唯一最终人物资产）、场景正反打、`STANDARD_FRAME_01` | 3–4 |
| `M1 部分素材` | 只出缺的那一半的概念基调，不重画用户已有的那一半 | 缺的那一半 + `ROLE_STILL_X` | 同上 | 2–3 |
| `M2 已有资产` | **不做人物**，只做视觉母版与场景基调 | 可选 `ROLE_STILL_X`（用户已给定妆照就直接复用） | 同上 | 1（+ 2 张裁切） |

**零素材时的三条硬边界**（在 4.1 四条边界之上追加）：

1. `CHARACTER_MOOD_X` 是**概念基调**，不是身份锚：它提供气质与面料方向，不提供五官；`FACE_CLOSE_X` 出 4 挑 1 锁定后，后续每一步都以它和 `ROLE_CHARTER_X` 为准。
2. 没有 `ROLE_STILL_X` 就直接拼三视图，脸与衣服容易各挑一个版本；零素材**建议先出定妆照**把二者锁进同一张全身图。
3. 过程资产（`CHARACTER_MOOD_X` / `OUTFIT_X` / `ROLE_STILL_X`）**一张都不进视频上传序列**；**唯一例外是 `FACE_CLOSE_X`**——v3.8 起它与 `ROLE_SHEET_X` 成对作为视频人物参考（专供近景锁脸）。不因为 `M0` 生成得多就多挂其它参考；色场由首帧、摄影母版与视频【参考绑定】的色卡共同继承。

用户只给一个图像模型时，按同样顺序由该模型全包，不拆分工。

## 5. 推荐组合（给 S1 用的起点）

| 场景 | 图像 | 视频 | 理由 | 35s 生成条 |
|---|---|---|---|---|
| **主推：最少跨生成跳色** | Seedream 5 / 即梦 | Seedance 2.5 | 同生态、色偏小；30s 上限 + 返回末帧 + 局部重绘 | 2 |
| **主推：强角色一致性** | Nano Banana 2 | Seedance 2.0 或 Kling 3.0 | 14 张参考锁角色 + 15s 多镜生成 | 3 |
| **英文 / 海外访问** | GPT Image 2 | Veo 3.1 | 结构化首帧 + 英文自包含时间码 | 5 |
| **低成本草稿 → 精修** | FLUX.2 / SDXL | Wan 3.0 → Seedance 2.5 | 先用 30s 长条验证节奏，再交主力精修 | 2 |
| **本地自控** | SDXL + LoRA | Wan 2.x 本地 | 无平台费用、可无限迭代 | 按档位 |
| **多模型三段接力**（4.1） | Midjourney 定基调 + Seedream 出人物 + Nano Banana 锁一致性 | Seedance 2.0 / 2.5 | 美感、人物、一致性各交给最擅长的模型；代价是多一道图片传递与一次取色固卡 | 不变，图像层不参与时长计算 |

> 不要全片只用单一模型的单次生成；高难度水面/纱镜头可换物理更稳的模型补拍，成片统一 LUT。
> 多模型接力只在用户有多个模型且愿意多一步传图时启用；单一模型能过 13 项与 6 项验收，就不要为分工而分工。

## 6. 小样验证协议（批量前必跑）

用**同一组固定描述串**一次性生成：

- 图像（**默认规格**）：每位角色 1 张 `ROLE_SHEET_X` 上下分区定妆板；`M0 零素材` 另加从零生成的 `FACE_CLOSE_X` / `OUTFIT_X` / `ROLE_STILL_X` 过程小样，`M2 已有资产` 只验裁切与拼板；再加场景空镜 3 张（远/中/近）+ 成品色卡出图提示词 1 张（**A 段取色 + C 段视频**）+ 标准首帧 1 张。参考图**不带色场与成片光影**（三点式 5500K 中性白棚光不属于成片光影），标准首帧才带。扩展包才需六类实例。
- 视频：1 条该模型最短档位，含斜后侧光 + 10–30% 失焦前景 + 1 个圆形道具 + 1 次手部动作 + 时间码切镜。

**默认先过上下分区定妆板 8 项**（`character-sheet-spec.md` 附录 A.3：上下 1/3 : 2/3 分区 / 正侧面头肩特写同一张脸 / 左下裁头放大且手脚完整 / 右下背面头到鞋完整 / 四格同人同妆造同服装 / 真实材质无 AI 油腻 / 纯净灰影棚三点式全清晰 / 无色场与文字）；`M0` 另过 `input-modes.md` §6 的输入模式 6 项。只有扩展包才过定妆包 13 项（`character-sheet-spec.md` 第 15 节：全身无裁切 / 纯色暖灰无缝背景 / 三点式中性光 / 头身比全包一致 / 三视图同一人且等大等高 / 四格版式 1:2 / 裁头格头出画且手脚完整 / 下方两格同人同服同配饰 / 真实皮肤与材质质感 / 无景深文字道具），再过下面成片画面 6 项。两套标准不能混用。

| # | 检查项（成片画面：标准首帧 / 空镜 / 镜头） | 不通过时先动什么 |
|---|---|---|
| 1 | 逐镜人物是否与定妆基准同一人（五官、发饰、服装固有色、头身比） | 补 `ROLE_REF_01` + `ROLE_TRIVIEW_01` + `ROLE_BOARD_01` 参考，固定描述串与 `body_ratio` 逐字复制 |
| 2 | 主色是否进入 ≥6 类载体、覆盖 3×3 九分区 | 补浅主色大面积载体、空气光、地面 |
| 3 | 是否出现斜后侧金色轮廓光、正面弱暖补光 | 改写光位段，加高位侧逆光描述 |
| 4 | 前景遮挡是否失焦、圆形道具是否形变 | 缩短镜头到 2 秒，或改为图像 + 极轻微动态 |
| 5 | 水 / 纱 / 雾 / 蒸汽是否崩坏、闪烁 | 负向词加 flickering/warping，或换物理更稳模型补拍该镜 |
| 6 | 运镜是否克制、时间码切镜是否被执行 | 显式写静态机位与切镜，按模型机制处理负向词 |

全部通过再批量。**顺序：先改参考图 → 再改提示词 → 最后才换模型。**

## 7. 色场一致性做法

0. 先生成**每位角色 1 张 `ROLE_SHEET_X` 上下分区定妆板（上 1/3 左正面 + 右侧面面部特写；下 2/3 左放大裁头正面服装图 + 右完整背面全身）**：出图提示词逐字采用用户定稿（v5.2），纯净灰色无缝影棚 + 正左主光 / 正右辅光 / 后右轮廓光三点式 + 全清晰 + 真实材质，禁 AI 油腻 / 塑料皮肤 / 过度美颜 / 廉价 CG，不带任何色场与成片光影；它一次性提供身份、比例、妆造、服装四朝向与材质基准。**前两格来源按输入模式**：`M0` 从零生成面部/服装/定妆照并以 12 项 `ROLE_CHARTER_X` 为身份锚，`M2` 从已有图裁切（见 `input-modes.md`）。扩展包才做面部四宫格与六类实例。
1. 用 `ROLE_SHEET_<主角>` + 场景参考 1 张（启用了可选反打是 `SCENE_REVERSE_01`，跳过则是 `SCENE_MOOD_01`）**两张参考**二次合成一张**标准首帧**（**不带色卡**）：包含主色、辅色、暖主光/冷环境光、低彩度浅主色载体、圆形锚点。
2. 其余所有生成条以该帧或其裁切作首帧 / 风格参考；**在 A 段场景图（取色彩方案）与 C 段视频【参考绑定】两处使用**，进 A 段场景图取色彩方案；每条同时逐字复用 `PHOTO_MASTER_01` 摄影母版文字块。
3. 角色固定描述串**逐字复制**，一次只改动作与景别。
4. 跨生成条用「返回末帧」续接（若模型支持），减少跳色。
5. 成片统一套一个 LUT：抬黑、压高光到奶油金、统一阴影色偏；不在生成阶段逐镜调色。

## 8. 常见坑

| 坑 | 后果 | 规避 |
|---|---|---|
| S0 就定模型 | 美学方向被工具条件带偏 | 总揽确认后才进 S1 |
| 只选视频模型 | 参考图包与首帧做不出来 | 图像 + 视频两层都选 |
| 用带场景/彩光/暖金逆光的半身图当定妆图 | 旧背景与同一道光被继承进每个镜头，色场锁死、转身换脸 | 按 `character-sheet-spec.md` 重出纯色暖灰影棚三点式中性光全身正面 + 朝向三视图 + 四格板 |
| 把「正面/四分之三/全身」当三视图 | 三个机位而非三个朝向，背面外观仍无依据 | 改为正面 0° / 正侧 90° / 背面 180°，等大等高 |
| 把 30s 上限当长镜头 | 崩坏率与成本上升 | 时间码拆 2–4s beat，剪辑切开 |
| 每镜独立文生视频 | 换脸、跳色 | 两类人物参考 + 标准首帧 + 色卡（仅【参考绑定】） |
| 负向词机制写反 | 越禁越出现 | 按模型机制改写，见 `model-adapter.md` |
| 用原生对白 | 破坏无对白节奏 | 后期加环境音与音乐 |
| **默认假设用户有人物图** | 零素材用户拿到裁切说明无法执行，S3 直接断链 | S0 判 `input_mode`，默认 `M0`，给从零生成的 `B-Z` 提示词组 + 12 项文字设定 |
| 零素材时把过程图也挂进视频 | 同信息重复输入、串脸 | 只挂 `ROLE_SHEET_X` + `FACE_CLOSE_X`，其余过程资产一张不上传 |
| 一上来开最高分辨率 | 迭代成本翻倍 | 小样 720p，成片再升 |

## 9. 选定之后：必须进入适配层

选型确认后运行（两层都要给）：

```bash
python3 scripts/model_adapter.py --video-model <视频模型> --image-model <图像模型> \
  --duration <成片总时长T> --aspect <画幅> --out-dir <项目目录>
```

输出 `adapted_prompt.md`、`adaptation_spec.md`、`usage_guide.md`、`generation_plan.json`，决定 S4 分镜表的镜数、每镜秒数、**生成条数**与 S5 的时间码结构。中途换模型 → 回退到 S1 重跑。

## 附录 · 视频上传序列与六块结构（v3.8，取代 v3.5 精简规则）

> **触发条件**：用户说「视频提示词不需要参考那么多人物资产」「人物只参考四视图资产和人脸特写」「场景图还是要参考色卡，只是色彩方案参考」「视频提示词要包含基本参数、参考绑定、摄影母版、禁止项、画面描述」。

1. **人物参考两类成对**：【参考绑定】里只出现 `@ROLE_SHEET_X`（四视图资产：五官 / 发饰 / 体型 / 比例 / 服装固有色 / 三视结构）与 `@FACE_CLOSE_X`（人脸特写：正面五官、眉眼鼻唇、肤质与妆造，专供近景与特写锁脸），**每位出镜角色成对上传**。三人同框 6 张、两人 4 张、无人物镜 0 张。**不要同时挂四宫格 + 定妆基准 + 四格板 + 单独三视图 + 服装放大**。**v5.1**：后景焦外可有 1–3 个不具名背景人影（v5.1 新增），他们**没有任何资产、不占参考位**，张数仍只按出镜主角算。
2. **不上传清单**：视觉母版、场景基调版、`CHARACTER_MOOD_X`、`OUTFIT_X`、`ROLE_STILL_X`、面部四宫格、服装放大图；`FABRIC_DETAIL_X` 仅在材质被画错时按需补 1 张。
3. **色卡两处使用（v4.2）**：`COLOR_CARD_01`（由 A08 成品出图提示词纯文字生成，12 个 HEX 写死）先给 `A01–A0N` 场景基调图与 `SCENE_REVERSE_0X`（若启用）**同传、只取色彩方案**，再到 C 段视频【参考绑定】上传；`A00` 母版、标准首帧与 B 段人物资产不挂色卡，全阶段不写 `--sref`。色卡必须先于 A01 完成。占比仍由色场方案表与摄影母版写死。**`SCENE_REVERSE_0X` 是可选资产**，由用户在 S3 选择用不用，不再每场景 A/B 两套、也不再是必传出口。
4. **摄影母版不占参考位**：`PHOTO_MASTER_01` 是文字块，v4.3 起为**一段连续专业摄影描述**（只写跨镜头统一项、不含具体焦段；焦段与 T 光圈下放到逐镜块），每条视频提示词逐字复用，不生成图、不上传。
5. **六块结构**：每条生成条按【视频基本参数】【参考绑定】【摄影母版】【禁止项】【画面描述】【收束与音频】整段交付；条间只改参数编号 / 具体资产 / 时间码。完整模板见 `prompt-examples-video.md` §8。
6. **参考位不够时**：优先保 `ROLE_SHEET_X`，人脸特写优先给近景多的生成条；色卡与首帧不可省。跨场景跳色归因于首帧、摄影母版与色卡，不归因于人物参考太少。
