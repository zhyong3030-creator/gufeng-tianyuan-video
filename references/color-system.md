# 色场系统：主色如何覆盖全画面又保持电影层次

来源：参考片片头成片 00:00–00:38 的逐秒降采样统计（160×90，色相族取中心色相 ±30°，剔除低饱和与极暗像素）。百分比为近似视觉占比，用于设定目标区间，不是精确色彩测量。

## 1. 片头成片的实测占比

| 色族 | 平均面积占比 | 主要落点 |
|---|---|---|
| 暖金橙 | 约 **65%** | 皮肤、发缘、白纱受光面、竹木、陶碗、水面反光、空气尘光 |
| 蓝青冷色 | 约 **21%** | 阴影、蓝袖、深水、远处屋檐、树影 |
| 绿 | 约 **4%** | 荷叶、枝叶、远景植被 |
| 近中性 | 约 **11%** | 高光核心、米白织物折中面 |

- 主色族在 **3×3 九个分区全部出现**，各区浓度不同但不是「只有中间有色」。
- 视觉上读成「蓝金交织」，像素上暖色仍占多数：**冷色负责结构与阴影，暖色负责光与人物**。这是综合色温，不是单层滤镜。
- 白衣受光面偏奶油金、褶皱偏蓝，画面里几乎不存在纯中性白。

## 2. 主色进入清单（换主题时逐项填写）

主色必须同时进入以下 8 类载体，缺一类就会出现「贴了滤镜」的观感。

| 载体 | 片头成片的进入方式 | 新主题填写要求 |
|---|---|---|
| 人物服装 | 米白/浅杏大面积低彩度承载主色，蓝袖做冷色支点 | 至少一件大面积极低彩度主色服装 |
| 皮肤 | 保留暖象牙，只有发缘与轮廓被主色光染 | 保持独立暖肤色 |
| 建筑 / 木构 | 赭黄木料、青灰屋檐分属暖冷两端 | 建筑主材落在主色中明度区 |
| 自然环境 | 水面反光、深水、荷叶、树影 | 自然面同时承担主色与留白 |
| 织物 | 薄纱、悬挂布把主色扩散成半透明层 | 至少一层半透明织物 |
| 道具 | 陶碗、竹匾、纺轮的中明度主色 | 圆形锚点必须是主色实体 |
| 地面 | 泥土、青石、湿岸的低明度主色 | 地面压深，托住画面下缘 |
| 空气与环境光 | 逆光尘雾、光晕、水面雾气 | 用体积光/雾把主色送进背景与空隙 |

## 3. 四个分层变量

### 3.1 明度

把同一主色拆成五级，禁止全画面同一浓度：

| 级别 | 角色 | 目标明度 |
|---|---|---|
| 近白高光 | 水面、纸、薄纱受光面 | V > 0.86，面积控制在 10% 以内 |
| 浅主色 | 大面积米白/浅杏服装、墙面 | 低彩度，承担 30–45% 面积 |
| 中主色 | 皮肤、木器、陶器、道具 | 画面主体明度区 |
| 深主色 | 树皮、地面、前景枝叶 | 压住画面边缘 |
| 阴影 | 蓝绿或棕褐，黑位抬高 | V < 0.22 的面积控制在 20% 以内 |

高色彩密度主要靠**大面积低彩度浅主色**承载，而不是全场高饱和。

### 3.2 综合色温

- 暖主光 + 冷环境光并存：面部、袖缘、空气尘光偏暖；水影、远树、屋檐、布料背光面偏冷。
- 目标配比参考片头：暖 : 冷 ≈ 3 : 1（65% / 21%）。做纯暖主题时也要保留 10–20% 冷色支点；做冷主题时暖色不低于 45%，否则肤色与光失去质感。
- 写法：在提示词里同时写「暖色斜后侧光」与「冷色环境反射 / 冷色阴影」，不要只写一个色温。

### 3.3 材质

| 材质 | 反光方式 | 产生的层次 |
|---|---|---|
| 布、纸、泥土、木材 | 漫反射 | 柔、低饱和、边缘软 |
| 水、金属、釉面、灯罩 | 镜面 / 窄高光 | 亮、硬边缘、小面积溢出 |
| 薄纱、雾气、尘光 | 半透 / 散射 | 把主色扩散到背景与空隙 |

同一色相靠反光差异形成不同亮度与边缘硬度，这是不靠加颜色就能出层次的关键。

### 3.4 空间距离

| 距离 | 饱和度 | 明度 | 清晰度 |
|---|---|---|---|
| 前景遮挡（10–30%） | 最高 | 最暗 | 失焦 |
| 中景人物与道具 | 中等 | 中等 | 清晰 |
| 远景屋檐、树林、水雾 | 最低 | 提高 | 虚化 |

叠加柔化高光后形成「前景遮挡 — 人物动作 — 环境空气」三层。

## 4. 人物不被主色吞没

- 浅主色服装承担大面积色场，脸、手、发缘保留独立暖肤色与轮廓光。
- 圆形道具框住动作焦点，主色从服装延伸到背景、地面与空气。
- 检查方法：把画面缩到缩略图，仍能一眼定位脸和手；若糊成一片色块，说明明度阶梯或轮廓光缺失。

## 5. 验收清单

### 量化（`scripts/color_field_audit.py`）

| 指标 | 目标 | 不达标时先做什么 |
|---|---|---|
| 主色族面积 | ≥ 55%（高色彩密度段可到 65–80%） | 提高低彩度浅主色载体面积，不要直接加饱和 |
| 九宫格覆盖 | ≥ 8/9 分区有色族像素 | 补空气光、地面、背景墙面 |
| 辅色族 | ≥ 10% | 补冷色阴影或环境反射 |
| 暗部 V<0.22 | ≤ 20% | 抬黑、加暖反射补光 |
| 高光 V>0.86 | ≤ 12% | 压高光、加柔光扩散 |
| 逐秒主色族跳变 | 相邻秒差 ≤ 20 个百分点（除刻意转场） | 统一首帧色卡与后期 LUT |

### 人工

- [ ] 肤色是暖象牙而非主色或冷灰
- [ ] 发丝/袖缘/道具边缘有金色轮廓光
- [ ] 至少 1 处 10–30% 的失焦前景遮挡
- [ ] 至少 1 个圆形锚点，位于中央或下三分之一
- [ ] 留白是带色的空气面，不是纯白/纯黑
- [ ] 前景—人物—远景三层可分辨
- [ ] 白衣褶皱有冷色，受光面有暖色
- [ ] 高光是奶油金，暗部仍有纹理

## 6. 常见失败

| 症状 | 原因 | 修正 |
|---|---|---|
| 像套了全局滤镜 | 所有载体同一明度、同一饱和 | 补五级明度阶梯与材质差异 |
| 画面糊成一块颜色 | 人物肤色被染、轮廓光缺失 | 恢复独立暖肤色与斜后侧轮廓光 |
| 脏、闷 | 暗部过多且死黑 | 抬黑 + 提高浅主色面积 |
| 塑料感、硬 | 高光纯白溢出、无柔化 | 奶油金高光 + 柔光扩散 |
| 色场只在中景 | 空气、地面、背景未进入主色 | 用雾气/体积光/地面色把主色铺满九宫格 |
| 镜头之间跳色 | 各镜独立生成、无统一首帧 | 锁首帧色卡，后期统一调色 |

## 7. 色卡：从归纳方法到成品出图提示词（v4.2，取代 v3.8 并补两处使用）

> **本节取代 v3.8「固定中文归纳提示词整段复制 + 同传多图出图」的做法。** 用户给的那段「12 色归纳」中文是**生成提示词的提示词（meta 指令）**，只指导归纳，不是可以粘到平台的出图提示词。把它原样粘进生图平台，得到的是「请分析…」这句话本身，不是色卡。

### 7.1 两步走（因果不可倒置）

```
参考素材（参考片画面帧优先；用户没给帧时才用视觉母版 + 场景基调图）
   ↓ ① 按 §7.2 的 12 色归纳 meta 指令做实际色彩归纳 + §7.3 分组检查
12 个 HEX + 主要用途 + 一句冷暖 / 饱和 / 明暗概括
   ↓ ② 写死成一条纯文字出图提示词（§7.4）
A08 COLOR_CARD_01（不传参考图、不挂 --sref；必须先于 A01 完成）
   ↓ 第一处：同传给 A01–A0N 场景基调图 + 可选反打（只取色彩方案，见 §7.8）
   ↓ 第二处
C 段视频提示词【参考绑定】
```

**有参考片画面帧时，色卡可在 A00 之前独立完成，且必须先于 A01 完成**，不与本项目 `A01–A0N` 场景基调图构成因果（反过来从场景图归纳色卡，六张图会各自跑色）。人物资产图不进归纳组（色卡不复述人物、产品与构图）。没有参考帧时，用 S0 色场方案表的固定风格取值 + 视觉母版 / 场景基调图归纳。

### 7.2 归纳 meta 指令（只作方法，不复制到平台）

```
请分析这些参考图共同的色彩规律，提取最能代表整体视觉氛围的 12 种左右颜色，并生成一张简洁色卡。
色卡建议包含：4 种主色、4 种辅助色、2 种强调色、1 种高光色和 1 种阴影色。每种颜色只需标注 HEX 色值和主要用途，例如背景、环境、主体、高光、阴影或局部点缀。
色卡下方再用一句话概括整体的冷暖倾向、饱和度和明暗感。不要复述参考图中的人物、产品和构图，也不要增加渐变色或过多相近颜色。如果参考图之间的色彩差异明显，请先提醒我重新分组，不要强行合并。
```

> ⚠️ 这三条是**给分析者 / 分析型模型的指令**。它指导「怎么归纳」，不描述「要画什么」。A08 交付的是 §7.4 的成品，不是这一段。

### 7.3 分组检查（归纳前必做）

把参考帧并排看一遍，或做一次像素聚类。若某几帧明显分成两组色温 / 色相（例如某帧冷蓝占比明显偏高），**先停下来提醒用户重新分组，不要强行合并**——合并两组会得到一张灰扑扑、谁都不像的色卡，后面每条视频都会跟着掉色。确定同组后再归纳；**实测取不到的颜色不要硬造**（例如没有可稳定提取的朱砂红，就不要凭空补一个）。

### 7.4 成品出图提示词模板（A08 真正交付的东西）

把归纳结果填进下面这条，**12 个 HEX 与用途写死**，纯文字生成、**不上传任何参考图**：

```
请生成一张简洁的平面色卡：纯色矩形色块，无渐变、无纹理、无投影、无立体效果，色块之间留细窄白边，背景为中性浅灰，色块面积均等。
全卡共 12 个色块，按四行排列，每个色块下方用清晰中文小字标注 HEX 色值和主要用途：
第一行 4 个主色：[#XXXXXX 用途]、[#XXXXXX 用途]、[#XXXXXX 用途]、[#XXXXXX 用途]；
第二行 4 个辅助色：[#XXXXXX 用途]、[#XXXXXX 用途]、[#XXXXXX 用途]、[#XXXXXX 用途]；
第三行 2 个强调色：[#XXXXXX 用途]、[#XXXXXX 用途]；
第四行 1 个高光色与 1 个阴影色：[#XXXXXX 用途]、[#XXXXXX 用途]。
色卡最下方单独一行中文小字：[整体冷暖倾向，饱和度中低，明暗跨度大；高光不漂白，暗部保留色相]。
画面中只有上述色块与标注文字，不出现人物、器物、产品、场景、构图或任何摄影描述；不添加渐变色，不添加与上列相近的额外颜色，不做调色偏移，色块的 HEX 值严格按给定数值呈现，文字保持清晰可读、不重叠。
--ar 3:4 --style raw --seed 1420
```

推荐中文小字能力稳的图像模型；平台参数行按实际平台替换。12 色**不负责面积占比**。

### 7.5 五条硬边界（v4.2 修订）

| # | 边界 | 说明 |
|---|---|---|
| ① | **两处使用，不是唯一处** | **第一处**：`A01–A0N` 场景基调图与 `SCENE_REVERSE_0X`（若启用）同传 `@COLOR_CARD_01`，**只取色彩方案**（见 §7.8）；**第二处**：C 段视频【参考绑定】上传，跨生成条锁色。色卡是色值清单，不是风格垫图。 |
| ② | **三处仍不挂色卡** | `A00` 视觉母版、`STANDARD_FRAME_01`（恒 2 参考）、B 段全部人物资产都不出现 `@COLOR_CARD_01`；**全阶段参数行都不写 `--sref`**，色卡走平台参考图槽位、由正文限定用途。 |
| ③ | **色卡不负责占比** | 12 色只给 HEX 与主要用途；主辅色面积占比、九宫格覆盖、五级明度、暖冷比仍由**色场方案表**与 `PHOTO_MASTER_01`【光影色彩】写死。色卡与它们并列，不是上下游取值关系。 |
| ④ | **成品提示词不传参考图** | 色值已写死，出图只靠文字；v3.8「同传视觉母版 + 场景基调图再归纳出图」的做法作废。 |
| ⑤ | **顺序不可倒** | A08 由参考素材独立归纳、纯文字出图，**必须先于 A01 完成**；先出场景图再回头归纳色卡属于旧因果链。 |

### 7.6 标准首帧与场景反打（v4.1）

`STANDARD_FRAME_01` 恒同传 **2 参考**：`ROLE_SHEET_<主角>` + 场景参考 1 张。`SCENE_REVERSE_0X` 是**可选**资产（S3 由用户自行选择）：选「用」时第 2 张是 `SCENE_REVERSE_01`；选「不用」时换成 `SCENE_MOOD_01`，并删掉 C 段【参考绑定】里的 `@SCENE_REVERSE_0X` 行、上传张数相应减少。旧口径「3 参考（色卡 + 拼板 + 场景版）」与「场景反打必传 / 每场景 A/B 两套」均作废，见 `staged-delivery.md`。

### 7.7 常见失败

| 症状 | 原因 | 修正 |
|---|---|---|
| 把「请分析这些参考图…」粘进平台，出不来色卡 | 把 meta 指令当成了出图提示词 | 按 §7.4 把归纳结果写成 12 个 HEX 写死的成品提示词 |
| 场景图出现色卡的方格版式 / HEX 文字，六个场景长得一样 | 用 `--sref` 或无差别垫图继承了整张色卡，正文也没写「只取色彩方案」 | 改用平台参考图槽位 + §7.8 的限定句；保留各场景独有的光位、空气与明度差异 |
| 色卡里塞进人物、器物与构图 | 归纳参考组混进了人物资产图 | 只留参考片画面帧 / 视觉母版 + 场景基调图 |
| 色卡出现一串相近的米色 / 渐变条 | 成品提示词没写死 HEX，或加了「相近色」 | 恢复 §7.4 模板，12 色按 4/4/2/1/1 分组写死 |
| 视频占比跟着色卡飘 | 把色卡当占比依据 | 占比回色场方案表与摄影母版 |
| 两组色温硬合出一张灰卡 | 没做 §7.3 分组检查 | 提醒用户重新分组后再归纳 |
| 六张场景基调图各自跑色，横排对不上 | 色卡出得比场景图晚，或没同传 | 按 §7.5 ⑤ 把 A08 提前到 A01 之前，六张同传同一张色卡 |

### 7.8 场景图怎么参考色卡（v4.2 新增）

色卡对场景图**只提供色彩方案**，不提供画面。`A01–A0N` 通用正文与可选反打提示词里固定写这一句，全部场景逐字一致：

> 以 @COLOR_CARD_01 为色彩方案参考：只取卡上的 12 色色值、主辅色结构与五级明度，不取色块的版式、HEX 标注文字与构图。

配套四条：

1. **同传方式**：色卡作为第 1 张参考图（反打时与 `@SCENE_MOOD_0X` 两张同传），走平台参考图槽位；**不写 `--sref`** —— `--sref` 会把色卡的方格版式、白边与中文小字一起当风格继承。
2. **A 段出图模型**：推荐 `gpt-image-2.5` 这类能吃多图参考、能理解指令式限定的图像模型；`A00` 视觉母版仍可由 Midjourney 类定基调，两者靠同一张色卡对齐。指令式模型末尾只写「画幅 16:9。」，不套 Midjourney 参数行。
3. **固定画质段**：通用正文含一整段画质约束，逐字一致：画面干净通透，真实的景深与空气透视，焦内细腻，焦外柔和虚化，光影纯净统一，色彩平滑，明暗过渡稳定，严禁噪点，杂乱纹理，斑点，过度锐化，色彩混乱，塑料感。 这段**只进 A 段图像提示词**；C 段【禁止项】仍按六块结构写正向句。画质段短语以用户确认的「明暗过渡稳定」为准。
4. **不变项**：占比、九宫格、五级明度仍由色场方案表与摄影母版写死；标准首帧恒 2 参考且不带色卡；人物资产不挂色卡；C 段六块结构与【参考绑定】照旧。

模板见 `assets/character-sheet-prompts.md` §15.4 / §15.5；硬规则见 `SKILL.md` 第 23 / 24 条。
