# 使用指引总纲：拿到文档之后到底怎么做

> **v5.4 提示词纯净补充**：视频提示词的代码块里**只写直接告诉 AI 的内容**；【视频基本参数】只写**视频时长 / 视频比例 / 视频类型 / 视频概述**四类。平台 / 模型 / 档位 / 生成条编号 / 成片时间码 / 挑片 / 记录种子 / 剪辑台衔接这些都是你在网页端选、在说明层看的操作信息，**不写进提示词、也不会丢**（框上方说明行 + 规划表 + 使用步骤）。详见 `SKILL.md` 第 31 条与 `references/prompt-examples-video.md` §8.8。
>
> **v5.8 手持基底运镜与视线补充**：每个逐镜块以**幅度清晰可辨的手持为基底**（上下浮动 / 左右摆移 / 构图找平、vlog 实拍感），其上按需**只叠一种**轻微推 / 拉 / 摇 / 移或轻微变焦；不剧烈抖动、不甩镜、无变焦冲击与急速推拉、不同时堆满多种；允许人物短暂自然看向镜头、不面对镜头表演。详见 `SKILL.md` 第 33 条与 `references/prompt-examples-video.md` §8.10。
>
> **v5.8 增量口径补充**：① 表情禁标签词、先写可见细节再点情绪分寸，代码块「笑」字 0；② `【镜头N | 0–5s | 名】` 是 2.5 时间戳切镜指令、允许进代码块，其余元信息一律框外；③ Seedance 2.5 单次 4–30 秒 / 参考 50 / `generate_audio: true` / 1080p 10bit mov / Draft / 不支持真人人脸参考 / 风格不与 2.0 混用；④ 配乐不进视频提示词，另出一条**独立全片 BGM**，剪辑台铺满、音量低于环境声，【收束与音频】逐字写「不要字幕，不要 bgm」；⑤ 帧模式二选一：传统首帧链路（默认）或 2.5 全模态参考生视频（不设首尾帧、只传多图参考）；⑥ A–D 说明层与「版权报错原样重提 1 次」口径。详见 `SKILL.md`「v5.8 增量口径」与 `references/prompt-examples-video.md` §8.11。
>
> **v5.3 跨场景「场景参照 @」补充**：一条 15s / 10s 生成条里如果装了不止一处场景，【画面描述】的**每个逐镜块正文开头**要逐字写 `场景参照 @SCENE_MOOD_0X；`，一镜一次、只 @ 本镜那一处；【参考绑定】不用重复写，句式不改、单场景条不强制。详见 `SKILL.md` 第 30 条与 `references/prompt-examples-video.md` §8.7。
>
> **v5.2 人物资产版式补充**：默认 `ROLE_SHEET_X` 是**上下分区定妆板**（上 1/3 左正面 + 右侧面面部特写；下 2/3 左放大裁头正面服装图 + 右完整背面全身），出图提示词**逐字采用用户定稿**、不改写；`Nano Banana Pro` 竖版 9:16，每位角色各跑一次、只换上传的参考图；`FACE_CLOSE_X` 从新板上方左格裁出后仍与拼板成对进视频。详见 `SKILL.md` 第 29 条与 `assets/character-sheet-prompts.md` §14.6。
>
> **v5.1 人物层级补充**：画面里的人分两层——主角（有身份资产、唯一清晰主体）与后景焦外的不具名背景人影（不出资产、不传图、不给正脸与特写）。视频上传张数只按主角算；**全片不用大远景 / 远景 / 大全景**，景别只在全景及更近档位之间拉开。详见 `SKILL.md` 第 28 条。

> **v5.0 用户视角入口（优先读）**：默认交付已改为**7 大步小白引导**（0 准备 / 1 视频总规划 / 2 视觉美学基调 / 3 视频分镜设计及脚本 / 4 人物场景资产设计 / 5 视频生成设计 / 6 自查）。每一小步弹 A / B / C 选择框，每一大步结束时在对话框**直接**给「每条提示词各一个独立一键复制框 + 一句话用法」，并落一份本地 `第N步_*.md`。下文各节是内部 S0–S7 的完整操作参考，供回答具体问题时查用，**不整份倒给用户**；规划 / 分镜 / 自查步不硬造提示词，只给表格清单。

> 本 skill 交付的是**规格 + 提示词 + 操作步骤**，不是媒体文件。这份文档规定「用户每一步该在哪个平台点什么、传什么、填什么、怎么验收」。
> 每阶段交付时，WorkBuddy 必须把**与本阶段相关的那几步**直接写进回复，不能只说「详见文档」。
> **v3.7 语言口径**：交付的提示词正文一律简体中文，可整段复制；代码块里保留原样的只有平台参数行（如 `--ar 16:9 --style raw --seed 1420`）、资产编号（如 `@ROLE_SHEET_A`）、器材型号与单位色值（`Black Pro-Mist 1/8`、`#C6BCB1`）、模型专有名——这些不是句子，不要改写、不要删。
>
> **v3.6 默认路径（先读）**：绝大多数用户**一张人物图都没有**，按 `M0 零素材` 走本文 §2A；有半套图走 `M1`，有完整资产走 `M2`（已有现成资产）。三种模式最终人物资产都只交**每人 1 张 `ROLE_SHEET_X` 上下分区定妆板**；视频层另按出镜角色成对加挂 `FACE_CLOSE_X` 人脸特写。§2B 的六类实例与 13 项验收是**扩展定妆包**，只有用户主动要求完整多视图时才做。判定与资产链见 `references/input-modes.md`。
>
> **v4.3 当前默认口径**：A08 色卡是**成品出图提示词**——先用「12 色归纳 meta 指令」对参考素材做实际归纳 + 分组检查，再把 12 个 HEX 写死成纯文字出图提示词、不传参考图，且**必须先于 A01 完成**。色卡**两处使用**：`A01–A0N` 场景基调图与可选反打**同传 `@COLOR_CARD_01`、只取色彩方案**（12 色色值 / 主辅色结构 / 五级明度，不取色块的版式、HEX 标注文字与构图），`C` 段【参考绑定】照旧上传；`A00` 母版、`A09` 标准首帧（恒 2 参考）与 B 段人物资产仍不挂色卡，全阶段不写 `--sref`。场景图推荐 `gpt-image-2.5` 类指令式图像模型，通用正文含固定画质段且逐字一致。`A01–A0N` 为「一条通用正文 + N 条场景句」；`SCENE_REVERSE_0X` 反打**可选**；提示词纯净原则不变（「参考图怎么用」允许进代码块）。v4.3 起摄影母版为一段连续专业摄影描述（只写跨镜头统一项、不含具体焦段），焦段与 T 光圈下放到【画面描述】的【镜头N | 时间码 | 镜头名】逐镜块；【画面描述】= 全局设定段 + 逐镜块，占比 / 光位 / 肤色 / 质感 / 人物锁定各只出现一次。规则见 `color-system.md` §7 / §7.8、`SKILL.md` 第 15 / 20–24 条与 `prompt-examples-video.md` §8。

## 2B. 图像层 · 扩展定妆包（仅用户主动要求完整多视图时；步骤 1–12 属扩展包）

> **最重要的一条**：角色定妆图和成片画面是两套东西，且**第一张图只能是面部四宫格**。定妆包 = **纯色暖灰 `#C6BCB1` 无缝影棚 + 三点式 5500K 中性白还原光 + 105mm（头）/85mm+（身）+ Tiffen Black Pro-Mist 1/8 低密度黑柔（仅高光轻晕）+ 清淡妆造无现代浓妆 + 全身正面头到鞋完整 + 锁定 `body_ratio` + 全画面清晰 + 真实皮肤与材质质感**；低密度黑柔**不是**柔焦 / 景深虚化 / 雾感 / 场景光晕。色场、**成片的**暖主光与金色轮廓光、前景遮挡、景深只进标准首帧；色卡 / 空镜 / 首帧不带影棚黑柔。完整规范见 `references/character-sheet-spec.md`，可复制模板见 `assets/character-sheet-prompts.md`。

1. **建项目目录**：`<工作区>/deliverables/color-field-<主题>/assets/`，后面所有参考图都放这里。
2. **出图前先过两组自检**：按 `references/character-design-aesthetics.md` 过角色设计 6 问（参考原片只取方法、三处记忆点、差异化清单 ≥3 条、反模板词、不复制原片人物），按 `references/costume-design.md` 过服装造型 6 问（六维表、四朝向结构清单、背面不空白、左右不对称侧别）。在 `theme_brief.md` 定稿 `[角色固定描述串]`、`[服装造型设计]`、`[四朝向服装结构]`、`body_ratio`（写实 7.5–8 / 古装风格化 8.5–9）、`face_spec` 模式（`unified` 默认 / `layered`）、黑柔档位（1/8 默认），确认 `FACE_REF_01` / `OUTFIT_REF_01` 是否上传，缺项记为假设。
3. **第一张只出 `FACE_QUAD_01` 面部特写四宫格**：粘贴模板 §1 提示词，出 4 张挑 1。核对：2×2 四等分、左上正面 0° / 右上左侧 90°（人物面朝画面右）/ 左下右侧 90°（人物面朝画面左，与右上互为镜像）/ 右下背面 180° 后脑发髻，四格全为头顶到锁骨的头部特写、同一人同一妆造同一尺度、眼位耳位对齐；暖灰背景、105mm、低密度黑柔、无现代浓妆、四格同一光位与滤镜档位。**左右两格出成同一张就逐格出再拼，不要靠 reroll。** 锁定后把描述串、头身比、面部规格模式逐字记进 QA 表，后面一个字不改。
4. **拆出四张面部单图**：`FACE_CLOSE_01..04`，分别对应四宫格四格；给单图输入模型用。
5. **色卡（v4.1 两步走，可最先做）**：先按「12 色归纳 meta 指令」对参考素材（参考片画面帧优先）做实际归纳、并排做分组检查（差异明显先提醒用户重新分组），得出 4 主 / 4 辅 / 2 强调 / 1 高光 / 1 阴影共 12 个 HEX 与用途；再把它们**写死成一条纯文字出图提示词**生成 `COLOR_CARD_01.png`，**不上传任何参考图**。那段归纳中文是**生成提示词的提示词**，不复制到平台。在 A 段场景图（取色彩方案）与 C 段视频【参考绑定】两处使用，先给 A 段场景图当色彩方案参考，也不负责占比。旧版「三段占比色块」与「同传多图用归纳指令出图」均作废。
6. **做影棚定妆基准图 `ROLE_REF_01`**：粘贴定妆模板，出 4 张挑 1。**面部严格以 `FACE_QUAD_01` 左上格为准**，提示词里写明引用关系。核对：头顶到脚底完整、暖灰无缝背景、三点式 5500K 中性白棚光、105mm/85mm+、低密度黑柔只柔化高光、无现代浓妆、全画面清晰、皮肤有真实质感、服装按六维与四朝向清单、不拿道具。**不要上传色卡、不要写主色占比、不要加 `--sref`，也不要把黑柔写进负向框。**
7. **出朝向三视图**：以 `ROLE_REF_01` + `FACE_QUAD_01` 对应格为唯一依据，只改机位朝向 → 正面 0° / 正侧面 90° `ROLE_REF_02` / 背面 180° `ROLE_REF_03`，拼成 `ROLE_TRIVIEW_01.png`（左正 / 中侧 / 右背，等大等高同一基线）。侧面与背面的发髻、耳后、颈后、衣领背面结构以四宫格对应格为准；固定 seed、逐字复制描述串、头身比与服装四朝向清单。**「正面/四分之三/全身」不是三视图**。
8. **出服装放大图与四格定妆板**：`ROLE_OUTFIT_DETAIL_01` 只管材质；`ROLE_BOARD_01` 上 1/3 直接取 `FACE_CLOSE_01/02`，下 2/3 左为放大裁头的正面服装图、右为常规背面全身（对应四宫格右下格）。左下格反复裁手裁脚或做成小全身时，按 `character-sheet-spec.md` §9.3 降级，不要硬凑。
9. **按定妆包 13 项验收**（`character-sheet-spec.md` 第 15 节）：四宫格四等分四朝向 / 面部统一规格 / 后面每张图都对应回某一格 / 全身无裁切 / 暖灰无缝背景 / 三点式中性光 / 头身比全包一致 / 三视图同一人等大等高 / 四格版式 1:2 / 裁头格头出画且手脚完整 / 真实皮肤与材质质感 / 服装四朝向清单且左右不换边 / 无景深文字道具。不通过就**先重出四宫格，再按顺序重出所有派生图**，不要只补一张；**不要拿色场、暖金轮廓光或柔焦标准去否定一张合格的定妆图**。
10. **场景空镜**：远景 / 中景 / 近景，命名 `SCENE_REF_01..03`。**从这里开始才写色场与成片光影**。
11. **标准首帧 `STANDARD_FRAME_01`**：默认规格只同传 **2 张**（`ROLE_SHEET_<主角>` + 场景参考 1 张：用了可选反打是 `SCENE_REVERSE_01`、跳过则是 `SCENE_MOOD_01`），**不带色卡**；扩展定妆包才把四宫格 + 01 + 三视图 + 四格板 + 一张场景空镜同时传给图像模型二次合成（同样不带色卡）；这一步才写主辅色占比、暖主光 / 冷环境光、低彩度载体、圆形锚点、10–30% 失焦前景、中浅景深。**这是全片色场一致性的地基，不是角色参考图，且不带影棚黑柔。**
12. **可选故事板九宫格 + 写 QA 表**：出一页 9 格编号分格图；记录每张图的模型、提示词 ID、seed / 参数、头身比、面部规格模式与黑柔档位、光照模式、引用了四宫格哪一格、参考了谁、挑图理由、13 项验收与设计/服装自检结论。

> 成片画面 6 项检查见 `references/model-selection.md` 第 6 节；不通过时顺序是「补参考图 → 改提示词 → 最后才换模型」。
> **默认视频层上传序列（v3.8，与输入模式无关）**：首帧（0–1 张）→ `COLOR_CARD_01`（**全片唯一出现位置**）→ 场景反打（可选）（按需）→ **每位出镜角色成对** `ROLE_SHEET_X` + `FACE_CLOSE_X`（三人同框 6 张、无人物镜 0 张）。`STANDARD_FRAME_01` 只同传 2 参考（主角拼板 + 场景反打（可选），**不带色卡**）。过程资产（`CHARACTER_MOOD` / `OUTFIT` / `ROLE_STILL`）**一张都不上传**，`FACE_CLOSE_X` 是唯一例外；服装材质特写只在画错时补 1 张。参考位不足时优先保 `ROLE_SHEET_X`；`PHOTO_MASTER_01` 是文字块，不占参考位。提示词里必须写「纯暖灰背景、三点式棚拍还原光、105mm 透视与 Tiffen 黑柔高光晕散一律不继承，不继承任何光位、光比、背景色与滤镜效果」。**v5.1**：后景焦外允许不具名背景人影，但**不占参考位、不上传任何人物图**；上面张数只按主角算。
> **扩展定妆包**才用：`COLOR_CARD_01 → STANDARD_FRAME_01 → ROLE_TRIVIEW_01 → ROLE_BOARD_01 → ROLE_REF_01 → FACE_CLOSE_01 → SCENE_REF_01`（`FACE_QUAD_01` 留作身份校验）；单图输入模型用 `FACE_CLOSE_01` 替换 `ROLE_BOARD_01`。
> 若出现「每镜同一道边光 / 跨视图明暗断层 / 轮廓光变暖金 / 黑柔变整屏雾感 / 暖灰染进服装固有色」，**整套**降级平光 + 无滤镜，或整套切 `--face-spec layered`，四宫格与所有单图一起重出。

## 3. 视频层：一次生成条怎么做（阶段 S6 必做）

以 `generation_plan.json` 的一个 unit 为单位：

1. **选对入口**：Seedance 走即梦/Dreamina 网页（豆包 App 只有 5/10s 预设）；Kling 走可灵网页或全球版；Veo 走 Flow/API；本地模型走 ComfyUI。
2. **上传素材**：按该模型 `reference_syntax` 上传，顺序为 `首帧 → COLOR_CARD_01 → SCENE_REVERSE_0X → [ROLE_SHEET_X, FACE_CLOSE_X] × 出镜人数`，**记住平台给的编号**；提示词里的 `@` 编号要与实际上传顺序一致，并写明「@ROLE_BOARD_01 上方两格只给面部细节、左下格只给服装材质、右下格只给背面外观；各图纯暖灰背景与三点式棚拍还原光一律不继承，不继承任何光位与光比」。单图输入模型改用 `FACE_CLOSE_01`。
3. **粘贴提示词**：正文贴时间码版；有独立负向字段的把 `negative_prompt.txt` 贴到负向框；参数化的把 `generation_params.json` 的值填进界面。
4. **设档位**：时长 = `unit_seconds`（必须 ≤ `max_duration_s` 且落在允许档位）；画幅按项目；分辨率先 480p/720p 打样，终版再升 1080p/4K；音频开关按模型规则处理，且提示词里已写「无对白」。
5. **生成 2–3 条**：不要只生成 1 条就定稿；Reroll 是正常流程（高星仓库案例里单镜常要 2–20 次）。
6. **挑片**：先看脸/服装有没有变，再看主色是否覆盖九宫格，再看光位与高光，最后看动作有没有做完。
7. **修错帧**：有局部重绘就只修那一帧；没有就重跑该条，**不要改一堆变量一起重跑**。
8. **续接**：支持「返回末帧」的模型把末帧导出，作为下一条首帧 `STANDARD_FRAME_02`，减少跨条跳色。
9. **命名归档**：`U01_S01-S06_15s_seedXXXX.mp4`，并写进 QA 表（时间码 / 模型 / 档位 / 参考编号 / 挑选理由）。
10. **一批最多 5 镜**，回传给我确认后才放行下一批。

## 4. 剪辑与统一（阶段 S7 必做）

1. 按分镜表把每个生成条**切回用户给定区间（建议 2–4 秒，可改）的 editorial shots**；长条不是长镜头。
2. 全片套**一个** LUT：抬黑、压高光到奶油金、统一阴影色偏；**不要逐镜调色**，逐镜调色会毁掉统一色场。
3. 加柔光/光晕只在成片层做一次；补环境音与一段克制配乐；不加对白、不加字幕朗读。
4. 只保留成片段跑验收：
   ```bash
   python3 scripts/color_field_audit.py <成片.mp4> --start 0 --end <成片时长> --out audit_report.json --csv audit_frames.csv
   ```
5. 六项不达标时按「标准首帧 → 提示词 → 统一调色 → 模型」顺序修，别一上来换模型。
6. 报告里分开写「实测数值」与「人工检查结论」。

## 6. 常见「不知道怎么做」的直接答案

- **提示词粘哪里** → 平台的主提示词框；负向词只在有独立负向框时贴进去，否则并按机制改写。
- **第一张图出什么** → 只出 `FACE_QUAD_01` 面部特写四宫格（四等分：正 / 左 90° / 右 90° / 背 180°，全为头部特写），出 4 张挑 1 锁定，再出后面的全身定妆图。理由：先锁四个朝向的五官与妆造，后面所有图才有同一张脸可依据。
- **参考图怎么传（v3.8）** → 先传首帧与 12 色色卡（色卡**只**在视频这一步传），再传场景反打（可选），最后每位出镜角色成对传 `ROLE_SHEET_X` + `FACE_CLOSE_X`；摄影母版是文字块、不上传。旧版「三视图 / 四格板 / 基准图 / 面部单图」全套同传是扩展定妆包写法，仅用户主动要求时用；`FACE_QUAD_01` 留作身份校验，参考位充足时再上传。多图模型按提示词里的 `@` 编号一一对应，并逐项写「继承什么 / 不继承什么」，尤其要写「暖灰背景、三点式棚光、105mm 透视与黑柔高光晕散一律不继承」。
- **定妆图能不能带光影和背景** → 不能带**成片的**光影与场景。它是纯色暖灰无缝影棚 + 三点式 5500K 中性白还原光 + 105mm/85mm+ + 低密度黑柔 + 无现代浓妆、全身正面、全清晰的生产参考资产；带暖金逆光与色场的半身图属于标准首帧，拿去当角色参考会把旧背景与同一道光带进每个镜头。**低密度黑柔是允许的**：它只让高光轻微晕散、去掉数字硬锐，不是柔焦 / 景深虚化 / 雾感 / 场景光晕，别把它写进负向框。`FACE_QUAD_01` 是四个朝向的头部特写，三视图是正面 / 正侧 90° / 背面 180° 三个朝向的**全身**，四格板是排版，三者不能互相替代。
- **角色怎么才不千篇一律** → 先按 `character-design-aesthetics.md` 定三处记忆点与差异化清单，按 `costume-design.md` 定服装六维与四朝向结构清单；撞脸先改设计（骨相、不对称细节、材质对比），不要靠多抽几次碰运气。
- **时长选几秒** → 看 `generation_plan.json` 的 `unit_seconds`；不要自己选最大档，除非该条确实要装那么多镜头。
- **要不要开原生音频** → 可以开，但提示词必须写「无对白、仅环境声」；不开就后期补。
- **生成条和镜头对不上** → 一条生成条里用时间码装多个短镜头，剪辑时切开；分镜表的「生成条 ID」列就是给这个用的。
- **换了模型怎么办** → 回退到 S1 重跑适配与整体规划，旧模型的提示词形态和镜数/条数一律不沿用。
- **颜色还是不统一** → 99% 是首帧 / 色卡 / 摄影母版没复用或没统一 LUT，不是模型不行；先按第 4 节第 2 步做。
- **场景图要不要参考色卡** → **要，但只取色彩方案**。色卡由参考素材独立归纳（有参考片帧时不依赖场景基调图），**必须先于 A01 完成**；先同传给 `A01–A0N` / 可选反打取色彩方案，再到 C 段【参考绑定】锁色，共两处使用。见 `color-system.md` §7.8。
- **场景反打必须做吗** → **不必须**。它是可选步骤；不用时删掉 C 段【参考绑定】的 `@SCENE_REVERSE_0X` 行、首帧第 2 张参考换 `@SCENE_MOOD_01`，上传张数相应减少，见 `SKILL.md` 第 21 条。
- **摄影母版在哪、要不要生成图片** → 在 `提示词全集.md` A 段 A10，v4.3 起是**一段连续专业摄影描述**（只写跨镜头统一项、不含具体焦段），**不生成图片、不上传**，C01–C03 逐字复制同一份；焦段与 T 光圈在【画面描述】逐镜块里单独给。
- **视频要传几张人物图** → 每位出镜角色 2 张（四视图资产 + 人脸特写）；三人同框 6 张。背景人影不传图、不计入张数，也不给身份资产。
- **某模型用不了** → 在 S1 换备选模型；若换的是时长上限差异大的模型（如 Veo 8s ↔ Seedance 2.5 30s），整体规划会重算，分镜表也会变。
- **能不能全自动出成片** → 能，但要你明确说「全自动出成片」；不必点名平台，libtv 没连上就换 WorkBuddy 内生成或你自己的平台批量。默认仍是逐步引导，不会因为省事就自动开跑（§8）。

## 8. 两条通道怎么选、怎么全自动出成片（v4.0 · autopilot）

> **默认仍是 `guided` 逐步引导**：不说话、说「先看看」、说「全部做完」都还是一步步来。只有你明确说「全自动 / 不用问我 / 直接出成片 / 一次做完」，才切 `autopilot`。**不必点名平台**：`libtv` 是优先后端，没连上就换 `workbuddy`（当前会话逐条生成）或 `external`（你自己的平台批量），两条通道都能跑到成片。

| 步骤 | 我做 | 你做 |
|---|---|---|
| 1 | 确认 `run_mode=autopilot`，一次性产出 S0–S5 全部文档，逐阶段写自动门禁记录 | 给主题；有参考图就给图，没有也照样能跑（`M0`） |
| 2 | `python3 scripts/build_handoff.py --project <项目目录> --backend <libtv\|workbuddy\|external>` 产出交接包三件 | **看一眼 manifest 的数量上限**（生成条数 × 挑片次数），确认可接受；顺带确认 `execution_backend` 选对了 |
| 3 | 整包交给选定后端：`libtv` 用 Canvas `run_agent(autoGenerate=true, idempotencyKey=…, documents=交接包 fileRef)` 或 agent-im 一条消息；`workbuddy` 按清单逐条生成；`external` 按批处理清单粘贴 | 明确授权这一次生成（libtv 平台侧还需 `confirmSpend` / 写权限） |
| 4 | 轮询 `get_agent_status`，回答 Agent 的追问，按数量上限盯住重跑次数 | 中途不用逐批确认 |
| 5 | **回读 artifacts + 实际导出成片**才算完成，再跑 `color_field_audit.py` 验收 | 拿成片链接 / 本地文件与验收报告 |

**三条硬边界**：① 交接包首段写死「提示词逐字执行、不得重写 / 扩写 / 翻译」，否则后端 Agent 会自己拆分镜写 prompt，色场就散了；② 色卡两处使用（A 段场景图只取色彩方案 + 视频【参考绑定】）、摄影母版是文字块不上传、人物参考两类成对，这些规则在自动模式下**一条都不放宽**；③ 超数量上限、平台报错或验收不达标即停并汇报，回退 `guided` 从 S5 继续，不删你的任何文件。

**libtv 没连上怎么办**：不用回退逐步模式，重新打包一次即可 —— `--backend workbuddy`（我在当前会话按清单逐条生成）或 `--backend external`（交接包变批处理清单，你在自己平台按序粘贴）。生产包与提示词一个字都不变，只换「谁按包执行」。

**想验证两条通道都能跑通**：`python3 scripts/verify_channels.py`（离线，不联网、不生成任何图片视频）。

完整协议（三种后端、两套 libtv 接法、幂等键、降级与失败回退）见 `references/agent-autopilot.md`。
