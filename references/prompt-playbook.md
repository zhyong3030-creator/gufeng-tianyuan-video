## 0. v3.7 / v3.8 七条新约束（写任何提示词之前先看）

1. **先有总揽**：提示词必须逐项落实 `master_overview.md` 里的美学设定、色彩氛围与光影特点，不能另起一套风格。
2. **图像 + 视频两层分别写**：定妆/定景提示词按**图像模型**形态写（对话式 / JSON / 关键词串 / 长句 + 参数）；逐镜提示词按**视频模型**形态写（时间码 beat、负向词机制、音频、参考绑定）。完整实例见 `references/prompt-examples-image.md` 与 `prompt-examples-video.md`。
3. **时间码由单次时长上限决定**：一条生成条装几个用户给定区间的镜头（建议 2–4 秒，可改），取决于 `generation_plan.json`；长条里每个 beat 只一个可见动作、切镜显式声明。上限不等于建议镜头长度。
4. **提示词必须配用法**：每条交付的提示词旁要写「粘到哪里 / 先传哪些参考（编号）/ 选几秒档位 / 生成几次 / 怎么挑片 / 怎么修错帧」。见 `references/usage-guide.md`。
5. **六段式只用于成片画面**：下面的六段（色场 / 圆形锚点 / 失焦前景 / 斜后侧主光 / 中浅景深）**不适用于角色定妆图**。定妆包按 @references/character-sheet-spec.md 走另一套：纯灰 `#B8B8B8` 无缝影棚 + 三点式 5500K 中性白还原光、全身正面、头到鞋完整、锁定 `body_ratio`、真实皮肤与材质质感；另外必产正/正侧 90°/背 180° 朝向三视图、上 1/3 面部特写 + 下 2/3 放大服装与背面全身的四格定妆板，以及六张单图。模板见 @assets/character-sheet-prompts.md。
6. **提示词一律简体中文（v3.7）**：所有交付给用户复制的提示词正文，包括本手册第 3 节三类模板、`prompt-examples-image.md` / `prompt-examples-video.md` 的实例、`character-sheet-prompts.md` 的模板与 `model_adapter.py` 生成的模板，全部写简体中文；不做中英双栏、不附英文版。**仅四类非句子内容保留原文**：① 平台参数行 `--ar 16:9 --style raw --seed 1420`（Midjourney 参数单独留在最后一行，不得删或译；**`--sref` 自 v3.8 起不再出现在场景图参数行**）；② 资产 ID `@ROLE_SHEET_A` / `COLOR_CARD_01`；③ 器材型号、单位与色值 `Black Pro-Mist 1/8`、`mm / 5500K / HEX`、`#C6BCB1`；④ 模型与平台专有名。器材型号用「中文名 + 型号」（天芬 Black Pro-Mist 1/8 黑柔滤镜）。**验收动作**：交付前扫全部三反引号代码块，若出现连续 5 个以上英文单词组成的句子即判不合格，先翻译再交付；研究用的英文原句只留在 `references/model-profiles.md` 的归纳里，不进交付包。


7. **视频提示词是六块结构，不是六段式（v3.8）**：下面第 1 节的「六段式」是**画面内容要素**清单，用于写【画面描述】；而每条生成条交付给用户的可复制提示词，外层必须是【视频基本参数】【参考绑定】【摄影母版】【禁止项】【画面描述】【收束与音频】**六块**。两套「六」不要混：前者管写什么，后者管怎么排版。硬口径：① `COLOR_CARD_01` 只出现在【参考绑定】；② 【摄影母版】= `PHOTO_MASTER_01` 中文文字块，逐字复用、不生成图、不上传；③ 人物参考只有 `@ROLE_SHEET_X` + `@FACE_CLOSE_X` 两类成对；④ 【禁止项】内部一律写正向句。完整模板见 `prompt-examples-video.md` §8，色卡规则见 `color-system.md` §7。

|---|---|---|
| 1 | 不写赞美形容词，写可见物件、光位、比例、机身镜头与物理反应 | `epic cinematic / 电影感 / 高级感` → `眼平 50–85mm 等效，右上高位斜后侧光，袖缘金色轮廓光，20% 失焦檐帘` |

| 3 | 时间码切分，每 beat 一个动作 + 切镜声明 | `她做了一系列动作` → `0–3s 捧起秤盘（切镜）；3–6s 药碾转半圈（切镜）` |

| 5 | 结尾留白，Reroll 是常态 | 结尾堆爆炸/台词 → `最后 3 秒无新动作、无对白，停在带主色的空气面` |

## 1. 六段式结构

每条提示词按固定顺序写六段，缺段即缺层：

| 段 | 内容 | 必须写清 |
|---|---|---|
| ① 主体与动作 | 谁、几个人、在做什么 | **只写 1 个可见动作**，不写情绪 |
| ② 色场 | 主色、辅色、低彩度承载物、暖主光 / 冷环境光 | 同时写暖冷两端，主色要落到具体物件 |
| ③ 构图 | 景别、人物占比、圆形锚点、框景、留白、前景遮挡比例 | 圆形锚点位置 + 10–30% 失焦前景 |
| ④ 光与质感 | 高位斜后侧光、弱暖补光、暖象牙肤色、抬黑、奶油金高光 | 柔焦、光晕、大而软的散景 |
| ⑤ 镜头 | 眼平、静态或极轻微推进、焦段倾向、中浅景深、三层 | 写「三层」而不是「有层次」 |
| ⑥ 负向 | 见第 5 节清单 | 每次都带，不省略 |

## 2. 可替换槽位（换主题只改这 12 格）

| # | 槽位 | 片头成片取值 | 说明 |
|---|---|---|---|
| 1 | 主题 / 场所 | 溪院、纺织院落 | 只换场所与劳作内容 |
| 2 | 主体 | 1–3 位素衣女子 | 人数 1–5，服装材质固定 |
| 3 | 动作 | 捧碗、理纱、撩水、俯身看竹匾 | 单动作、可完成 |
| 4 | 主色 | 暖金橙 | 占 55–80% |
| 5 | 辅色 | 蓝青 | 占 10–25%，落在阴影与远景 |
| 6 | 浅主色载体 | 米白薄纱 | 大面积低彩度，承担色场 |
| 7 | 圆形锚点 | 碗口、竹匾、纺轮、水波弧 | 中央或下三分之一 |
| 8 | 前景遮挡物 | 花枝、白纱、荷叶 | 10–30%，失焦 |
| 9 | 空气面 / 留白 | 溪水、水雾、米色天空 | 低对比且带主色 |
| 10 | 光位 | 高位斜后侧（左上或右上） | 相对人物角度不变 |
| 11 | 景别 / 焦段 | 中近景 / 50–85mm 等效 | 每镜只选一档 |
| 12 | 时长 | 用户给定区间（建议 2–4 秒，可改） | 不写长镜头 |

### 示例 A：雪夜药铺（主色 靛蓝 + 烛金）


## 6. 一致性技巧

- **固定描述串**：脸型、发饰、服装材质与颜色写成一段固定字符串，逐字复制到每条提示词，一个字都不改。
- **参考图 ID**：`FACE_REF_01`（面部）/ `OUTFIT_REF_01`（服装）/ `ROLE_REF_01`（影棚全身正面）/ `ROLE_TRIVIEW_01`（正侧背）/ `ROLE_BOARD_01`（四格板）/ `FACE_CLOSE_01`/`FACE_CLOSE_02`（面部单图）/ `ROLE_OUTFIT_DETAIL_01`（服装放大）/ 场景参考 / 色卡 / `STANDARD_FRAME_01` 分别编号；每条视频提示词引用同一组 ID，并写明「纯暖灰背景与三点式棚拍还原光一律不继承，不继承任何光位与光比」。
- **首帧锁色**：所有镜头共用一张标准首帧或其裁切；成片统一 LUT，不逐镜调色。
- **单变量迭代**：一次只改动作或景别中的一个，避免同时换光位与服装导致无法定位问题。
- **色卡作为 style reference**：写明「主色族占比约 65%、辅色约 20%、近中性约 10%」，比形容词有效。
- **短镜头优先**：用户给定的单镜区间（建议 2–4 秒，可改）内动作可完成即可，动作没写完就缩短动作而不是拉长时长。

## 7. 提示词与分镜的对应

每个分镜 → 1 条视频提示词 + 复用 ① 的角色参考包（`ROLE_REF_01` + `ROLE_TRIVIEW_01` + `ROLE_BOARD_01`；单图输入模型改用 `FACE_CLOSE_01`）+ ② 的场景空镜 + ③ 的色卡 + ④ 的标准首帧。分镜表里记录提示词 ID 与参考图 ID，避免生成时张冠李戴。详见 @references/script-template.md。

## 8. 按模型改写（升级后必经）

六段式**内容不变，形态随模型变**。产出任何提示词前，先按 @references/model-adapter.md 与 `scripts/model_adapter.py` 的适配规格改写：

| 模型差异 | 提示词怎么改 |
|---|---|
| 英文优先 | 按 adapter 第 4 节六段逐段译，不压缩成风格词 |
| 多图参考 | 前置参考图绑定段，脸/服装/场景/色卡分别指定 ID |
| 单图输入 | 改用一张标准首帧，角色外观写进正文，固定描述串逐字重复 |
| 短单镜时长 | 动作压到建议时长的 70% 内，超出就拆镜 |
| 原生音频 | 必须写「无对白、无口播、无字幕朗读」 |
| 独立负向字段 | 负向词分离到 `negative_prompt.txt`，正文不重复 |
| 参数化模型 | 末尾附参数行（Midjourney `--ar/--seed/--style`，**v3.8 起不写 `--sref`**；开源 seed/CFG/steps） |
| **character 阶段** | **不套六段式**：第一张先出 `FACE_QUAD_01` 面部四宫格（四等分，正/左90°/右90°/背180°全为头部特写），再按影棚定妆基准图 + 朝向三视图 + 四格定妆板 + 六张单图模板写；写死 `body_ratio`、三点式中性光、105mm/85mm+、低密度 Tiffen 黑柔、无现代浓妆与真实质感，并按 `--face-spec unified|layered` 整套统一；每条派生图写明引用四宫格哪一格、服装六维与四朝向清单；去掉 `--sref 色卡`、去掉主色占比与成片主光段；另产 `character_prompts.md`、`character_sheet_checklist.md`（13 项 + 设计/服装/对应性自检） |
| 9:16 | 前景遮挡降到 10–20%，留白从左右改为上下 |

`scripts/model_adapter.py --video-model <视频> --image-model <图像> --stage <character|scene|video> --base <现有提示词.md>` 会在原提示词前后自动插入模型专属段、能力表、写法规则、**完整实例**与使用步骤，并按单次时长上限重排生成条与时间码；自然语言改写与英文翻译仍按本手册与 adapter 规则完成。
