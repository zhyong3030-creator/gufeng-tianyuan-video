# 服装造型设计：让角色立得住，也让色场有落点（S0 定稿 · S3 逐格对应）

> **v4.3 当前默认口径**：A08 色卡是**成品出图提示词**——先用「12 色归纳 meta 指令」对参考素材做实际归纳 + 分组检查，再把 12 个 HEX 写死成纯文字出图提示词、不传参考图，且**必须先于 A01 完成**。色卡**两处使用**：`A01–A0N` 场景基调图与可选反打**同传 `@COLOR_CARD_01`、只取色彩方案**（12 色色值 / 主辅色结构 / 五级明度，不取色块的版式、HEX 标注文字与构图），`C` 段【参考绑定】照旧上传；`A00` 母版、`A09` 标准首帧（恒 2 参考）与 B 段人物资产仍不挂色卡，全阶段不写 `--sref`。场景图推荐 `gpt-image-2.5` 类指令式图像模型，通用正文含固定画质段且逐字一致。`A01–A0N` 为「一条通用正文 + N 条场景句」；`SCENE_REVERSE_0X` 反打**可选**；提示词纯净原则不变（「参考图怎么用」允许进代码块）。v4.3 起摄影母版为一段连续专业摄影描述（只写跨镜头统一项、不含具体焦段），焦段与 T 光圈下放到【画面描述】的【镜头N | 时间码 | 镜头名】逐镜块；【画面描述】= 全局设定段 + 逐镜块，占比 / 光位 / 肤色 / 质感 / 人物锁定各只出现一次。规则见 `color-system.md` §7 / §7.8、`SKILL.md` 第 15 / 20–24 条与 `prompt-examples-video.md` §8。

> 为什么单独写这份：脸锁死了，服装最容易滑进「通用古风 / 仙侠白纱 / 影楼写真」；而**服装是主色进入画面的最大载体**——角色图里的领型、层数、材质、固有色，直接决定 `STANDARD_FRAME_01` 能不能把主色铺满九宫格。
> 与 `character-design-aesthetics.md`（管脸与整体美感）、`character-sheet-spec.md`（管拍摄规格）并列；对应性矩阵见 `character-sheet-spec.md` §4.4。
> 适用：`[角色固定描述串]` 的服装部分、`ROLE_REF_01..03`、`ROLE_TRIVIEW_01`、`ROLE_BOARD_01`、`ROLE_OUTFIT_DETAIL_01`、`STANDARD_FRAME_01`、逐镜提示词。

## 1. 六维设计表（每一维都要落到可见物件，不写「华丽 / 精致 / 仙气」）

| 维度 | 必须写清 | 反例（禁） | 正例 |
|---|---|---|---|
| ① 形制 | 领型（交领 / 圆领 / 立领）、襟向、袖型与袖口宽、腰线位置、下摆长度与开叉、鞋履、层数 | 「古装 / 汉服 / 长袍 / 传统服饰」 | `交领右衽、窄袖收口、腰线在自然腰位、下摆至脚踝、右侧开叉至膝下、深褐布鞋` |
| ② 层次 | 内 / 中 / 外各是什么、每层露出位置与大致面积 | 「层层叠叠 / 很有层次」 | `内层米白中衣仅在领口露 5%，中层靛蓝棉袍为主体，外层米白围裙覆盖躯干正面约 40%` |
| ③ 材质 | ≥2 种反射率不同的材质相邻，写明漫反射 / 半透 / 镜面 | 「布料轻盈飘逸」 | `粗棉漫反射 + 半透纱 + 铜扣窄镜面高光；粗棉有织纹与压皱` |
| ④ 配色与色场接口 | 服装固有色对应 S0 的**主色 / 浅主色载体 / 辅色点睛**哪一个；各色在人物身上约占多少面积 | 定妆图里写「主色 65%」或 `--sref` | `靛蓝为主体固有色、米白为大面积低彩度载体、烛金发绳为小面积点睛` |
| ⑤ 配饰与呼应 | 发饰 / 腰饰 / 随身器物，与 S0 的**圆形锚点、框景材质、主色道具**呼应；道具 1–2 个头宽 | 「配饰精美」 | `素色发带 + 腰间铜秤盘（与下三分之一圆形锚点同材质）` |
| ⑥ 不对称与生活痕迹 | 一处不对称细节（写明左 / 右）+ 一处使用痕迹 | 左右完全对称、全新无褶 | `右袖口多一道挽边、左襟有磨边、袖口自然压皱` |

**功能性要求**：服装必须能支撑 S0 里那个「一个可见动作」——药铺学徒要能抬手称量、渔人要能弯腰拉网、灶前的人袖口要收得住。写不进动作的服装，多半只是摆拍模板。

## 2. 四朝向服装结构清单（与 `FACE_QUAD_01` 的对应）

> 用户强调「后面的人物定妆图也要对应」：不只是脸，**服装在四个朝向各自可见什么，也要先列清楚**，再让三视图 / 四格板照着出。背面空白或与正面矛盾是最常见的崩点。

| 朝向 | 必须写出的结构 | 对应资产 |
|---|---|---|
| 正面 0° | 领口叠压顺序、襟向、围裙 / 外搭覆盖边界、腰饰正面、鞋头 | `ROLE_REF_01`、`FACE_CLOSE_01`、`ROLE_BOARD_01` 上左 / 下左、`ROLE_TRIVIEW_01` 左格 |
| 左侧 90° | 左袖口形状、左侧开叉或系带、侧缝走向、发饰侧面固定方式、**左襟磨边** | `FACE_CLOSE_02`、`ROLE_REF_02`、`ROLE_BOARD_01` 上右 |
| 右侧 90° | 右袖口挽边、右侧开叉高度、腰饰侧面、配饰挂点；与左侧**不互换** | `FACE_CLOSE_03`、右侧机位、`ROLE_TRIVIEW_01` 中格（若取右侧） |
| 背面 180° | 后领形状、背中缝 / 褶裥、下摆背面垂坠、腰带在背后的结法、发髻背面固定、鞋跟 | `FACE_CLOSE_04`、`ROLE_REF_03`、`ROLE_TRIVIEW_01` 右格、`ROLE_BOARD_01` 右下格 |

**锁定规则**：这一清单与 `[角色固定描述串]` 一起在 S0 定稿，逐字复制进所有角色图提示词；`ROLE_REF_01` 的服装是固有色与形制的唯一基准，三视图 / 四格板 / 放大服装图只能改机位与取景，不能改设计。

## 3. 反千篇一律：服装专属禁令

1. 禁模板词：`仙侠白纱 / 广袖流仙裙 / 通用古风 / 汉服小仙女 / 影楼装 / 华丽宫装 / 飘逸仙气 / 精致刺绣`（除非主题确实要，且写出具体纹样）。
2. 禁「只有正面好看」：左右不对称细节必须能在对应侧被看见；背面必须有可描述结构。
3. 禁「一套服装打天下」：换主题必须重写六维表；只换颜色不改形制，仍然会被认成同一套模板。
4. 禁「材质全同」：至少两种反射率相邻，否则黑柔与暖主光打上去没有层次。
5. 禁「配饰只为好看」：每件配饰要么呼应圆形锚点 / 框景材质，要么在动作里被用到；否则删掉。
6. 禁把成片色场写进定妆图：定妆图只写**固有色**；主色占比、暖主光、环境反射、前景遮挡属于 `STANDARD_FRAME_01` 与逐镜提示词。

## 4. 与成片色场的桥接（很重要，别把两层混了）

| 层 | 写什么 | 不写什么 |
|---|---|---|
| 定妆包（四宫格 / 三视图 / 四格板 / 放大服装图） | 服装固有色、形制、层次、材质、配饰、四朝向结构 | 主色占比、`--sref`、暖主光方位、金色轮廓光、九宫格覆盖、柔焦 |
| `COLOR_CARD_01`（12 色归纳卡） | HEX 色值与主要用途；**在 A 段场景图（取色彩方案）与 C 段视频【参考绑定】两处使用** | 人物、产品、构图；不负责占比与五级明度 |
| `STANDARD_FRAME_01` / `SCENE_REF_*` | 把主色写进服装、建筑、织物、道具、地面、空气与环境光，覆盖九分区 | 影棚背景、三点式棚光、黑柔 |
| 逐镜提示词 | 引用 `@ROLE_REF_01` 的固有色 + 该镜的光位与动作 | 重新描述一遍服装设计 |

**换主色时（v4.1）**：按归纳 meta 指令对新的参考素材重做一次 12 色归纳 + 分组检查，**重写 A08 成品出图提示词里的 12 个 HEX**，并改首帧正文、摄影母版的【光影色彩】与逐镜提示词，**不必重出角色包**；只有服装固有色本身改了，才回 S0 重定 `[角色固定描述串]` 并按 `character-sheet-spec.md` §13 重出全部派生图。

## 6. 服装造型自检 6 问（S3 出图前与角色设计自检一起过）

| # | 问题 | 命中后改什么 |
|---|---|---|
| 1 | 六维表有没有任意一维还写着抽象形容词？ | 换成可见物件 / 位置 / 面积 / 材质 |
| 2 | 四朝向清单里背面是否为空或与正面矛盾？ | 补后领、背中缝、腰带背后结法、下摆背面 |

| 4 | 至少两种反射率不同的材质相邻了吗？ | 补粗棉 / 半透纱 / 金属一组 |
| 5 | 服装固有色是否已对齐 S0 主色 / 浅主色载体 / 点睛色？ | 回到 S0 色彩氛围表对齐，别在定妆图里写占比 |
| 6 | 这套衣服能做出 S0 那个可见动作吗？换了主题还像同一套模板吗？ | 加功能性结构（收袖 / 围腰 / 开叉），换主题重写六维表 |
