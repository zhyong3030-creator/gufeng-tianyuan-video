> **v4.3 当前默认口径**：A08 色卡是**成品出图提示词**——先用「12 色归纳 meta 指令」对参考素材做实际归纳 + 分组检查，再把 12 个 HEX 写死成纯文字出图提示词、不传参考图，且**必须先于 A01 完成**。色卡**两处使用**：`A01–A0N` 场景基调图与可选反打**同传 `@COLOR_CARD_01`、只取色彩方案**（12 色色值 / 主辅色结构 / 五级明度，不取色块的版式、HEX 标注文字与构图），`C` 段【参考绑定】照旧上传；`A00` 母版、`A09` 标准首帧（恒 2 参考）与 B 段人物资产仍不挂色卡，全阶段不写 `--sref`。场景图推荐 `gpt-image-2.5` 类指令式图像模型，通用正文含固定画质段且逐字一致。`A01–A0N` 为「一条通用正文 + N 条场景句」；`SCENE_REVERSE_0X` 反打**可选**；**v5.4 起提示词纯净升级**：C 段代码块只写直接告诉 AI 的内容，【视频基本参数】只写视频时长 / 视频比例 / 视频类型 / 视频概述，平台 / 模型 / 档位 / 编号 / 时间码 / 挑片 / 记录种子 / 剪辑台衔接全部移到说明层（见 §8.8）；「参考图怎么用」仍允许进代码块。v4.3 起摄影母版为一段连续专业摄影描述（只写跨镜头统一项、不含具体焦段），焦段与 T 光圈下放到【画面描述】的【镜头N | 时间码 | 镜头名】逐镜块；【画面描述】= 全局设定段 + 逐镜块，占比 / 光位 / 肤色 / 质感 / 人物锁定各只出现一次。规则见 `color-system.md` §7 / §7.8、`SKILL.md` 第 15 / 20–24 条与 `prompt-examples-video.md` §8。

## 1. 同一部示例 35 秒片，三种模型的整体规划完全不同（`T` 可改）

`model_adapter.py` 会按 `max_duration_s` / `duration_options` 自动算出下表。**这就是「最长时长」影响分镜与规划的地方**：

| 模型 | 单次上限 | 成片镜头 | 每镜秒数 | **生成条数** | 每条装几个镜头 | 规划后果 |
|---|---|---|---|---|---|---|
| **Seedance 2.0** | 15s | 14 | 2.5s | **3**（15+15+5） | 6 / 6 / 2 | 一条覆盖约两个叙事段落；段落内不跨生成，跳色风险低 |
| **Seedance 2.5** | 30s | 14 | 2.5s | **2**（30+5） | 12 / 2 | 一条几乎装下全片；必须写 12 段时间码并显式声明切镜；可用「返回末帧」续接 |
| **Kling 3.0** | 15s | 14 | 2.5s | **3**（15+15+5，档位取 15/15/5） | 6 / 6 / 2 | 用 Shot 1…Shot 6 多镜模式，负向框只填稳定性瑕疵 |
| **Veo 3.1** | 8s | 16 | 2.19s | **5**（8×4 + 4） | 3–4 / 条 | 生成次数最多；每条 8s 内排 3–4 个 2–3s beat；跨条一致性最脆弱，首帧与色卡必须逐条复用 |
| **Runway Gen-4.5** | 10s | 14 | 2.5s | **4** | 4 / 条 | 无负向词，禁项全部靠正向句；后期补环境音 |
| **海螺 2.3** | 10s（1080p 仅 6s） | 16 | 2.19s | **6**（6s 档） | 3 / 条 | 只出近景与手部特写，群像交别的模型补拍 |

> **上限 ≠ 建议镜头长度。** 无论哪个模型，成片镜头按用户给定区间（建议 2–4 秒，可改）；长上限只用来把相邻镜头合成一次生成，减少跨生成换脸与跳色。剪辑时按分镜表切回短镜头节奏。

## 2. 五段式结构 → 时间码 → 生成条（示例：Seedance 2.5，30s 主条）

| 段落 | 成片时间 | 功能 | 情绪 | 镜头数 |
|---|---|---|---|---|
| A 定场近景 | 0–6s | 捧铜秤盘、脸部与服装确立 | 静 | 2 |
| B 关系中景 | 6–14s | 两人递药包、器械进入画面 | 缓 | 3 |
| C 质感特写 | 14–22s | 药碾、蒸汽、纸绳、烛火 | 密 | 4 |
| D 动作高潮 | 22–30s | 三人各做一个动作、雪被风带起 | 扬 | 2 |
| E 逆光收束 | 30–35s | 停在雪夜空气与烛火 | 收 | 1 |

生成条 1（0–30s）→ 12 个 editorial shots，用时间码显式切镜；生成条 2（30–35s）→ 1 个收束镜头。
若换成 Veo 3.1，同样五段会被拆成 5 条 8s，每段跨 1–2 条，需要在段落边界额外做首帧续接。

## 3. 通用时间码写法（每个 beat 只一个可见动作）

```
[参考职责] @ROLE_REF_01（影棚全身正面定妆图）只提供五官、发饰、体型、body_ratio 与服装固有色；
@ROLE_TRIVIEW_01 只提供正侧 90° 与背面 180° 的外观；@ROLE_BOARD_01 上方两格只提供面部细节、左下格只提供服装材质、右下格只提供背面外观；各图的纯暖灰背景、三点式棚拍还原光与三格/四格排版一律不继承，不继承任何光位与光比。
@SCENE_REF_01 只提供空间布局；@COLOR_CARD_01 只提供色场占比；
@STANDARD_FRAME_01 为首帧，提供主光方位、轮廓光、前景遮挡与景深。
以上各项之外一律不继承（inherit-nothing-else）。
[色场] 靛蓝 65% / 烛金 20% / 近中性 15%；暖主光 + 冷环境反射；米白围裙为大面积低彩度载体。
[光与质感] 右上高位斜后侧暖主光；发丝与袖缘烛金轮廓光；暖象牙肤色；暗部抬高保留木纹；奶油金高光柔化；柔焦、大而软的散景。
[镜头] 眼平静态、仅极轻微推进；中浅景深；失焦前景—清晰主体—虚化远景三层。
[圆形锚点] 铜秤盘 / 药碾轮 / 纸包口，位于下三分之一。
[前景] 左上 20% 失焦檐帘，全程不移动。
[时间码]
0–3s  A1 中近景：学徒双手把铜秤盘从药柜前抬起，视线落向盘内。切镜。
3–6s  A2 近景：她低头，烛火在铜边滑过一道窄高光。切镜。
6–9s  B1 中景：另一人把纸包递到画面中央，两人手不接触。切镜。
……
[收束] 最后 3 秒不加新动作、不加特效、不加对白，停在带靛蓝的雪夜空气。
[音频] 无对白、无口播、无字幕朗读，只有环境声。
```

## 4. 各模型完整实例

### 4.1 Seedance 2.0（15s 档，中文 + `@` 绑定）

```
参考绑定：@ROLE_REF_01（影棚全身正面）只提供五官、发饰、体型、body_ratio 与服装固有色；@ROLE_TRIVIEW_01 只提供正侧 90° / 背面 180° 外观；@ROLE_BOARD_01 上方两格只提供面部细节、左下格只提供服装材质、右下格只提供背面外观（各图纯暖灰背景、三点式棚拍还原光与拼版排版一律不继承，不继承任何光位与光比）；@SCENE_REF_01 只提供雪夜药铺空间；@COLOR_CARD_01 只提供靛蓝 65% / 烛金 20% 色场；@STANDARD_FRAME_01 为首帧，提供主光方位、轮廓光、前景遮挡与景深。以上之外一律不继承。
0–3s：学徒双手把铜秤盘从药柜前抬起，视线落向盘内；中近景，眼平静态只极轻微推进。切镜。
3–6s：药碾缓缓推过半圈，蒸汽升起；特写，烛金窄高光沿铜边移动。切镜。
6–9s：她低头把药末扫入纸包；中近景，左上 20% 失焦檐帘保持不动。切镜。
9–12s：另一人把纸包递到画面中央；中景，两人手不接触。切镜。
12–15s：停在纸包与雪夜空气，无新动作，无对白。
全程：靛蓝 65% 进入棉袍、药柜、青砖、雪影与空气；烛金 20% 只在皮肤、烛火、铜边与发丝轮廓；米白围裙低彩度承载。右上高位斜后侧暖主光、冷环境反射、暖象牙肤色、抬黑保留木纹、奶油金高光柔化；中浅景深三层；圆形锚点在下三分之一。只有环境声，无对白、无口播、无字幕朗读；画面内不出现文字、水印、现代物件、环绕运镜、甩镜、变焦冲击。
```

**怎么做**：即梦/Dreamina **网页端**选 Seedance 2.0（不用 Fast）→ 上传 5 个参考并记住编号 → 正文粘贴，`@` 逐项指定 → 时长选 15s（豆包 App 只有 5/10s 预设，别承诺 15s）→ 生成 2–3 条挑 1 → 导出末帧，作为下一条的首帧 → 记录 seed / 时长 / 参考编号。

### 4.2 Seedance 2.5（30s 档，长条 + 局部重绘 + 返回末帧）

```
参考职责：@ROLE_REF_01 控制五官、体型、body_ratio 与服装固有色，@ROLE_TRIVIEW_01 控制侧面与背面外观，@ROLE_BOARD_01 上方两格给面部细节、左下格给服装材质、右下格给背面外观（各图都不继承纯暖灰背景、三点式棚拍还原光与任何光位光比），@SCENE_REF_01 控制雪夜药铺布局，@COLOR_CARD_01 控制色场，@STANDARD_FRAME_01 为首帧，@STANDARD_FRAME_02 为尾帧；除此之外不继承任何内容。
0–3s 捧起铜秤盘（中近景，切镜）；3–6s 烛火滑过铜边（近景，切镜）；6–9s 药碾转半圈、蒸汽升起（特写，切镜）；9–12s 扫药末入纸包（手部特写，切镜）；12–15s 两人递纸包（中景，切镜）；15–18s 系纸绳（特写，切镜）；18–21s 抬眼望窗外雪（近景，切镜）；21–24s 檐帘被风带起（中景，切镜）；24–27s 逆光三人各做一个动作（群像中景，切镜）；27–30s 停在雪夜空气与烛火，无新动作。
每段时间码内只发生一个可见动作；切镜必须显式声明，机身保持眼平、采用幅度清晰可辨的手持摄影，其上只叠一种轻微推进。靛蓝 65% / 烛金 20% / 近中性 15%；高位斜后侧暖主光 + 冷环境反射，暖象牙肤色，抬黑保留木纹，奶油金高光柔化，中浅景深三层；圆形锚点在下三分之一，左上 20% 失焦檐帘全程不动。只有环境声，无对白、无口播、无字幕；不出现文字、水印、环绕、甩镜、变焦冲击。
```

**怎么做**：选 **Media to video** → 上传首/尾帧与全套参考并用 `@` 编号 → 分辨率先 480p/720p，时长按 `generation_plan.json` 的 `unit_seconds`（30s）→ 打开「**返回末帧**」便于续接 → 生成后若只有某一帧手错了，用**局部重绘**修那一帧，不要整条重跑 → 升 1080p/4K 出终版 → 末帧导出为下一条的 `STANDARD_FRAME_02`。

### 4.3 Kling 3.0（15s 多镜模式，负向框只写瑕疵）

```
Shot 1（0–3s）：学徒把铜秤盘从药柜前抬起，视线落向盘内，中近景。
Shot 2（3–6s）：药碾推过半圈，蒸汽升起，特写。
Shot 3（6–9s）：低头把药末扫入纸包，中近景。
Shot 4（9–12s）：另一人把纸包递到画面中央，中景，两人手不接触。
Shot 5（12–15s）：停在纸包与雪夜空气，无新动作。
全程参考 @STANDARD_FRAME_01 与 @COLOR_CARD_01：靛蓝 65% / 烛金 20%，靛蓝进入棉袍、药柜、青砖与空气，烛金只在皮肤、烛火、铜边与发丝轮廓；米白围裙为低彩度载体。右上高位斜后侧暖主光、冷环境反射，暖象牙肤色，抬黑保留木纹，奶油金高光柔化；眼平静态，仅极轻微推进，中浅景深三层；圆形锚点在下三分之一，左上 20% 失焦檐帘。无对白、无口播、仅环境声。切镜必须显式，不自动运镜。
```
负向框：`脚部滑动、多余手指、形变`（**只写具体稳定性瑕疵**）

**怎么做**：图生视频上传首帧 → 正文贴 Shot 1…Shot 5 → 负向框只填上面三个词 → 时长 15s → 生成 2–3 条抽查脸与色场 → 记录档位与 seed。**敏感词过滤很严**，提交前净化可能被误判的身体/接触词。

### 4.4 Veo 3.1（8s，中文自包含 + 纯名词负向）

```
腰部以上、眼平机位，一位年轻药铺学徒，鹅蛋脸，深棕低髻配素发带，靛蓝棉袍外罩米白麻布围裙，暖象牙肤色，双手捧着一只铜秤盘。主色靛蓝约 65%，覆盖棉袍、药柜、青砖地与夜色空气；辅色烛金约 20%，只落在皮肤、烛火、铜器边缘与发丝轮廓；米白围裙为低彩度载体。0–3 秒：她把秤盘从药柜前抬起，视线落向盘内。3–6 秒：药碾转半圈，蒸汽升起。6–8 秒：她低下头，画面停在纸包与雪夜空气上，不再有新动作。右上高位斜后侧暖主光，暗部冷环境反射，暖象牙肤色，抬黑并保留木纹，高光奶油金并柔化扩散，左上 20% 失焦檐帘，铜秤盘口位于下三分之一作圆形锚点，三层结构为失焦前景 / 清晰主体 / 虚化远景。机身保持眼平、采用幅度清晰可辨的手持摄影，其上只叠一种轻微推进，50–85mm 等效。无对白，仅环境声。
```
负向框（**纯名词，禁止写 no/don't 这类否定句**）：`多余肢体、故障形变、文字、水印、现代物件`

**怎么做**：Flow / API 选 Veo 3.1 → 上传标准首帧 → 正文贴中文时间码、负向框贴纯名词 → 时长 **8s，不用 Extend** → Fast 版先打样，终版用完整模型 → 生成 3 条挑 1 → **剪辑时把 8s 切成 3 个 2–3s 镜头**。5 条生成条之间必须复用同一首帧与色卡，成片统一 LUT。

### 4.5 Runway Gen-4.5（10s，零否定句）

```
药铺学徒的腰部以上眼平画面，靛蓝棉袍外罩米白围裙，双手捧着一只铜秤盘。靛蓝充满棉袍、药柜、青砖地与夜色空气；烛金只留在皮肤、烛火、铜器边缘与发丝轮廓。暖象牙肤色，抬黑并保留木纹，高光奶油金并柔化扩散，左上 20% 失焦檐帘，铜秤盘口位于下三分之一作圆形锚点，三层由清晰到柔和。秤盘从药柜前缓缓抬起；蒸汽向上飘散；画面最后停在纸包上。镜头：眼平锁定，仅有呼吸般极轻微的浮动，50–85mm 等效。环境音在后期补入。
```

**怎么做**：上传首帧 → 正文**只写应出现的画面，不写任何 avoid/no** → CAMERA 段单独写静态与极轻微浮动 → 时长 10s → 生成后剪成 3–4 个短镜头 → 后期补环境音（模型无原生音频）。

### 4.6 Wan 3.0 / 开源（30s 低成本草稿）


## 5. 负向词机制对照（写错会反向生效）

| 模型 | 机制 | 正确写法 | 禁止写法 |
|---|---|---|---|
| Veo 3.1 | 独立字段，只认纯名词 | `extra limbs, glitch morphs` | `no rain` / `don't morph` |
| Kling 3.0 / Wan | 独立字段，只写具体瑕疵 | `脚部滑动、多余手指、形变` | `低质量、不好看` 这类泛词 |
| Runway Gen-4.5 | **完全不支持** | 只写「应该出现什么」 | 任何 `avoid X` / `no X` |
| Seedance 2.0 / 2.5 | 消费端无可靠字段 | 正向句「画面内不出现文字」「其余一律不变」 | 命令式 no/don't |
| Nano Banana / 海螺 | 无字段或少用 | 正向约束句 | 大段负向清单 |
| Sora 2（deprecated） | 无字段 | 正文 guardrails | — |

## 6. 失败 → 修复顺序（不要一上来换模型）

1. **错帧** → 有局部重绘就只修那一帧（Seedance 2.5）；否则重跑该生成条。
2. **换脸 / 换服装** → 补角色参考图、加 inherit-nothing-else、把角色固定描述串逐字复制。
3. **跳色** → 复用同一 `STANDARD_FRAME_01` 与 `COLOR_CARD_01`；跨条用「返回末帧」续接；成片统一 LUT。
4. **动作被截断 / 结尾崩** → 按时间码把动作拆到两个 beat，或降低 `unit_seconds`。
5. **水面 / 纱 / 蒸汽闪烁** → 负向框加 `flickering/warping`，或该镜改「图像 + 极轻微动态」。
6. **自动运镜** → 正文写静态机位、CAMERA 段锁死；Runway 只能用正向描述。
7. **整条被拒** → 净化措辞（Kling/Veo 敏感词过滤会命中外观描述，不只是专有名词）。
8. 以上都无效，**最后**才考虑换模型，并回退到阶段 S1 重跑适配与整体规划。

## 7. 逐镜提示词自检（10 项）

1. 每个 `@参考` 是否写清继承/不继承？
2. 生成条时长是否 ≤ 该模型 `max_duration_s` 且落在允许档位？
3. 是否用时间码把长条拆成 2–4s 的 editorial shots、每镜一个动作？
4. 切镜是否显式声明（不靠模型自己切）？
5. 负向词是否符合该模型机制？
6. 带原生音频是否写了「无对白、仅环境声」？
7. 主色是否覆盖 3×3 九分区、进入 ≥6 类载体？
8. 光位、肤色、暗部、高光是否逐项写明且无抽象赞美词？
9. 结尾是否留白（无新动作、无特效、无对白）？
10. 是否记录 seed / 档位 / 参考编号 / 挑片理由到 timestamped QA 表？

> 适用：所有视频模型、所有输入模式、所有主题。每条生成条**整段复制、六块齐全**，缺一块判不合格。细则见 `SKILL.md` 第 15–18 条。

### 8.1 六块固定结构

| 块 | 写什么 | 条与条之间可否改 |

| 【视频基本参数】 | **v5.4：只写四类直接告诉 AI 的内容** —— `视频时长` / `视频比例` / `视频类型` / `视频概述`（自然描述句）；**不写**模型与平台、档位、生成条编号、成片时间码、分辨率与帧率等平台表单项、首帧来源、切点数、生成次数与记录项；这些全部搬到框外说明层（§8.8） | ✅ 换主题 / 时长只改这四类 |

### 8.2 `PHOTO_MASTER_01` 摄影母版文字块（v4.3 一段式，S0 固化一次，不上传）

> **它不是一张图、不上传、不占参考位。** 来源是 S0 影像总揽的「光影特点 / 摄影设定」两节，写进 `提示词全集.md` 的 A 段，C 段每条逐字复制。**v4.3 起按参考截图改为一段连续专业摄影描述，不再分三个子标签**：只写跨镜头统一不变的东西（机身 / 镜头组 / 帧率 / 快门 / ISO / 整体质感 / 色彩密度与主色控制原则 / 肤色分离 / 不磨皮不锐化），并承载「颜色可以很淡，但高光不能漂，暗部也必须保留色相」这句色彩体积原则。下面方括号是换主题时唯一允许替换的槽位，其余句式不变。

```
统一使用数字电影摄影机与定焦镜头组，24fps，180 度快门，ISO 800；真实电影摄影质感，自然运动模糊，柔和高光滚降，宽容度充足。画面保持高色彩密度与明确主色控制，中间调留住 [主色名] 的综合色彩，高光为奶油金并柔化扩散但不漂白，暗部抬高仍压住 [辅色名] 且保留木纹、织纹、砖缝与陶土颗粒，让暖调有胶片般的色彩体积，不出现数码荧光与廉价高饱和感。肤色恒为暖象牙到蜜桃，与暖绯环境清晰分离，保留真实毛孔与细绒，不磨皮、不过度锐化。天芬 Black Pro-Mist 1/8 低密度黑柔滤镜，柔光与光晕全片统一加一次，不逐镜叠加。机身眼平、全程静态，靠画面内遮挡与剪辑换景。颜色可以很淡，但高光不能漂，暗部也必须保留色相，这样统一色场才有体积。
```

**母版写什么 / 不写什么（v4.3）**：

| 写进母版（跨镜头统一项） | 下放到别处（可变项） |
|---|---|
| 机身与定焦镜头组、24fps、180 度快门、ISO 800、整体质感（运动模糊 / 高光滚降 / 宽容度）、色彩密度与主色控制原则、肤色分离、不磨皮不锐化、黑柔滤镜、眼平静态、色彩体积原则句 | ① 单一焦段与 T 光圈、机位高度 →【画面描述】逐镜块；② 面积占比与九宫格 →【画面描述】全局段；③ 三层结构比例、圆形锚点位置、焦点转移 → 逐镜块 |

「摄影机和镜头组可以统一，但不同分镜需要根据画面重新选择焦段和光圈」——母版里出现任何 `mm` 数值都算回退，会变成同镜多焦距互相干扰。母版也不从色卡取占比，占比由色场方案表写死、在全局段陈述一次。

### 8.7 跨场景「场景参照 @」规则（v5.3 · 唯一权威）

> 用户 2026-11-11：「如果一个 15s 内有不止一个场景，那画面描述中需要将场景资产艾特出来」，并选定写法 A「场景参照 @ID」、要求同步 skill。

**逐字句式**（放在每个 `【镜头N | 时间码 | 镜头名】` 逐镜块的**正文第一行**）：

```text
场景参照 @SCENE_MOOD_0X；前景是……
```

**映射示例**（本项目 40 秒 / 8 镜 / 3 条，只作格式示范，不随主题与时长变化）：

**边界**：

1. 只进【画面描述】逐镜块；【参考绑定】仍逐张写「提供什么 / 不继承什么」，**不重复**绑定说明；全局段、【摄影母版】、【禁止项】、【收束与音频】一律不新增这句。

### 8.10 手持基底运镜与视线（v5.8 · 唯一权威）

### 8.11 v5.8 增量口径（表情 / 2.5 规格 / 声音 / 帧模式 · 唯一权威）

**表情写法**：禁标签式定性词，先写可见细节（嘴角 / 眼睑 / 视线 / 下颌 / 肩线 / 呼吸 / 指节 / 节奏与停顿）再点明这一镜的情绪与分寸；代码块里「笑」字为 0；各镜情绪谱系不重样、不全是笑。人物层级定稿句按 §8.9 逐字写，主角唯一性半句与背景五项禁令一条不少。

**纯净原则的例外**：`【镜头N | 0–5s | 名】` 是 2.5 的**时间戳切镜指令**（条内相对时间），是唯一允许进代码块的编号型文字；平台 / 模型 / 档位 / 生成条编号 / 张数 / 挑片 / 种子 / 剪辑台 / 跨步说明仍全部在说明层（§8.8）。

**Seedance 2.5 官方规格**：单次 4–30 秒；参考上限 50（约 30 图 + 10 视频 + 10 音频）；时间戳切镜最小 1 秒；`generate_audio: true` 可在正文写「不要字幕，不要 bgm」只出环境声；1080p 10bit mov + PCM，Draft 先打样；不支持真人人脸参考；风格不与 2.0 混用；强烈情绪易触发瞳孔发光，须写「眼睛与瞳孔保持自然、不发光、不出现异色光」；多人物按首次出场顺序传参考。

**独立全片 BGM**：配乐不进视频提示词。另出一条独立全片配乐提示词，单独生成音频、剪辑台铺满、音量低于环境声；【收束与音频】逐字写「**不要字幕，不要 bgm**」+ 环境声正向句；`generate_audio` / mov 10bit PCM / Draft 等只在说明层写。

**两种帧模式（S0 按模型选，不混用）**：① 传统首帧链路（默认）：`STANDARD_FRAME_01` 恒 2 参考、可末帧续接；② 2.5 全模态参考生视频：**不设 `first_frame` / `last_frame`**，只传多图参考，条内时间戳切镜 + 条间剪辑台干净硬切。**参考图不是首帧，但必须决定视频内容**；「不是首帧」只放开镜头起点 / 景别 / 人物姿势 / 机位，不放开场景 / 主题 / 核心生活事件。

**A–D 说明层**：A 上一条；B 表情反面佐证；C 事件不可替换 + 三节拍；D 一镜一种主运动。**报错**：版权报错多为平台偶发误判，原样重提 1 次即可，不改词 / 不换账号 / 不连点重跑。
