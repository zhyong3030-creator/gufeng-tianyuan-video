# 视觉语法：跨色彩段落始终稳定的摄影规律

来源：参考片片头成片 00:00–00:38。以下规律在该段落内不同色温、不同人数、不同场景的镜头之间保持一致。换主题时逐条照搬，只替换物件与题材。

## 1. 尺度关系

| 对象 | 相对人物的尺度 | 换主题时的处理 |
|---|---|---|
| 碗、竹匾、纺轮、杯盘、托盘 | 直径约头宽 1–2 倍 | 换成新主题的等价圆形道具，尺寸不变 |
| 树、门楼、屋檐、院墙 | 约人物高度 1.5–3 倍 | 保持可逼近的庭院/作坊尺度，不做宏大建筑 |
| 水面、地面、天空 | 作为低对比的「空气面」，不参与尺度竞赛 | 换成晒场、雾面、雪面、滩涂等同一功能面 |

环境永远不放大到人物的十几倍。因此无论写实溪院还是风格化场景，都不会出现纪念碑式全景，**也不会出现大远景 / 远景 / 大全景**（用户 2026-11-08 二次纠偏「不要用大远景和远景」）：这类景别会把人物缩成点，失去唯一尺度基准。

## 2. 景别与构图

- **景别配比（锁定风格口径，v5.1 回退）**：腰部以上中近景 ≈ 50%，两三人中景 ≈ 30%，手部/器物特写 ≈ 15%，全身带环境群像 ≈ 5%。**禁用大远景、远景、大全景**，不做纪念碑式空镜头。用户明确要求「多人物 / 拉开景别 / 不要全是单人」时，只在**全景、中景、中近景与过肩、近景、特写、俯拍、微距**之间拉开，人物仍是唯一尺度基准。上一版把景别配比放开并允许大远景是错误判断，已回退。
- **人物占比**：单人占画面高度 1/3–2/3；群像横向铺开 2–5 人，不纵向堆叠。
- **位置**：人物居中或偏下三分线，动作与器物形成横向或斜向连线。
- **留白**：低细节水面、米色天空、墙面承担留白；留白必须是**低对比、带主色的空气面**，不是纯白或纯黑空区。
- **运镜**：眼平机位，静态或极轻微推进，靠剪辑换景，不做甩镜、环绕、变焦冲击。

### 2.1 人物层级（v5.1 · 唯一权威）

> 用户 2026-11-08：「也可以有背景人物，不一定只有她们三个人物，只是这三个人物是主要表现的人物」。

| 层级 | 身份资产 | 允许 | 禁止 |
|---|---|---|---|
| **主角**（S0 定下的出镜角色） | `ROLE_SHEET_X` + `FACE_CLOSE_X`，每人 2 张 | 唯一清晰正脸、唯一近景与特写、唯一明确动作线、清晰焦平面 | —— |
| **不具名背景人影** | **无**，一张都不出、一张都不传 | 后景焦外虚化层，每镜 1–3 人；劳作 / 挑担 / 过路；服装取环境中间调融进色场；每镜独立、不要求同人 | 名字、参考图、参考位、清晰正脸、特写、与主角同一焦平面、独立动作线、可辨识发饰 / 首饰 / 服装形制 |

**逐镜写法**：背景人影只写在【画面描述】逐镜块的「三层空间 → 背景」与「环境动态」，不写进动作 / 焦点 / 切点；【禁止项】用正向句写「背景人影保持在后景焦外、身份不作刻画、三位主角始终是唯一清晰主体」；【参考绑定】与【收束与音频】都不新增人物描述。人影的缓动算环境动态，不算破坏「每镜只做一个动作」。

## 3. 圆形结构与框景

- **圆形锚点**：碗口、竹匾、纺轮、油纸伞、荷叶、水波弧线、水花团。每个镜头至少有一个，落在画面中央或下三分之一，不做完全对称的徽章式构图。
- **第二层框**：花枝、树枝、木柱、窗棂、悬挂织物、纱衣在人物外缘形成框。
- **框景规则**：框架属于前景层，允许失焦；人物与核心道具保持清晰。

## 4. 前景遮挡

- 树干、白花、纱衣、荷叶、水花、托盘边缘常占画面 **10–30%**，且失焦。
- 前景越靠近镜头，颜色越深、越饱和；中景人物为中间明度；远景提亮降饱和并虚化。
- 前景遮挡同时承担「把主色压到画面最前层」的功能，因此不可省略。

## 5. 摄影机质感、焦段、景深

| 项目 | 稳定表现 |
|---|---|
| 质感 | 柔焦、轻微光晕、高光晕开、大而软的散景；不是硬锐数字质感 |
| 焦段倾向 | 群像约 35–50mm、中近景约 50–85mm、器物特写约 85–135mm 等效；为透视判断，不是设备参数 |
| 景深 | 中浅景深：清晰平面只留给脸、手或核心道具；前景遮挡与远景同时虚化 |
| 层次 | 至少保留「失焦前景 — 清晰人物/动作 — 虚化环境空气」三层 |

## 6. 主光、肤色、暗部、高光

- **主光**：高位斜后侧光，约在摄影机反方向 120–150°；画面上表现为左上或右上，方向可变但相对人物的角度不变。正面只用弱暖反射补光。
- **结果**：发丝、袖缘、水面、道具边缘持续出现金色轮廓光，正面不过曝。
- **肤色**：暖象牙—蜜桃，独立保留，不随主色变冷灰。
- **暗部**：带蓝绿或棕褐倾向，黑位抬高、保留纹理；不做死黑。
- **高光**：奶油金而非纯白；仅水珠、金属、灯笼小面积溢出，并伴随柔光扩散。

## 7. 换主题等量替换表

把片头成片的物件按**功能**替换，而不是按外形硬套：

| 功能位 | 片头成片 | 雪夜药铺 | 海边渔火 | 麦收晒场 |
|---|---|---|---|---|
| 圆形锚点 | 碗、竹匾、纺轮 | 药碾、铜秤盘、陶罐口 | 鱼篓、竹筛、浮球 | 竹匾、石磨、簸箕 |
| 空气面 / 留白 | 溪水、水雾 | 雪面、药炉蒸汽 | 海面、夜雾 | 麦浪、扬尘 |
| 前景遮挡 | 花枝、白纱、荷叶 | 檐帘、药柜格、飘雪 | 渔网、芦苇、浪花 | 麦秆、麻布、草帽 |
| 主色载体（织物） | 白纱、蓝袖、米白衣 | 靛蓝棉袍、米白围裙 | 赭褐蓑衣、灰蓝头巾 | 米白麻衣、麦黄头巾 |
| 主色载体（建筑/地面） | 木构、青石、泥土 | 深木药柜、青砖、积雪 | 船板、礁石、湿沙 | 土墙、竹架、晒谷地 |
| 轮廓光来源 | 斜后侧日光穿枝叶 | 斜后侧窗光 + 烛火 | 斜后侧夕照 + 渔灯 | 斜后侧午后日光 |

替换原则：每个功能位都必须保留，且新物件尺寸、明度层级、材质反光方式与原位相当。

## 8. 常见偏差

- 把「斜后侧光」写成「逆光」而让正面全黑：需要保留弱暖补光与抬黑。
- 为了突出主题把建筑放大成地标：破坏人物尺度基准。
- 前景遮挡做成清晰实焦：丢失三层结构。
- 让主色染到脸上：肤色独立是这套画面的可读焦点，不能让位。
