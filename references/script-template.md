# 脚本与分镜：把片头成片的节奏抽象成可换主题模板

> **v4.3 当前默认口径**：A08 色卡是**成品出图提示词**——先用「12 色归纳 meta 指令」对参考素材做实际归纳 + 分组检查，再把 12 个 HEX 写死成纯文字出图提示词、不传参考图，且**必须先于 A01 完成**。色卡**两处使用**：`A01–A0N` 场景基调图与可选反打**同传 `@COLOR_CARD_01`、只取色彩方案**（12 色色值 / 主辅色结构 / 五级明度，不取色块的版式、HEX 标注文字与构图），`C` 段【参考绑定】照旧上传；`A00` 母版、`A09` 标准首帧（恒 2 参考）与 B 段人物资产仍不挂色卡，全阶段不写 `--sref`。场景图推荐 `gpt-image-2.5` 类指令式图像模型，通用正文含固定画质段且逐字一致。`A01–A0N` 为「一条通用正文 + N 条场景句」；`SCENE_REVERSE_0X` 反打**可选**；提示词纯净原则不变（「参考图怎么用」允许进代码块）。v4.3 起摄影母版为一段连续专业摄影描述（只写跨镜头统一项、不含具体焦段），焦段与 T 光圈下放到【画面描述】的【镜头N | 时间码 | 镜头名】逐镜块；【画面描述】= 全局设定段 + 逐镜块，占比 / 光位 / 肤色 / 质感 / 人物锁定各只出现一次。规则见 `color-system.md` §7 / §7.8、`SKILL.md` 第 15 / 20–24 条与 `prompt-examples-video.md` §8。

> **v3.3 角色参考包变更**：第一张图必须是 `FACE_QUAD_01` 面部特写四宫格（同一图四等分：正 / 左 90° / 右 90° / 背 180°，全为头部特写），后面每张定妆图按 `character-sheet-spec.md` §4.4 对应性矩阵指回它；全包统一纯色暖灰 `#C6BCB1` + 三点式 5500K 中性光 + 105mm（头）/85mm+（身）+ 低密度 Tiffen 黑柔 + 无现代浓妆；另产朝向三视图、四格定妆板与六张单图，定妆包验收 13 项。出图前先过 `character-design-aesthetics.md` 设计自检 6 问与 `costume-design.md` 服装自检 6 问。本文件涉及角色参考包的具体表述以 `character-sheet-spec.md` 为准。

## 1. 片头节奏抽象（N 段式 · 总时长 `T` 与镜数由用户给定）

> **时长不卡死**：下表是 35–38 秒 / 5 段 / 13–15 镜的**建议示例**，时间列按 `T` 换算、段落与镜数按用户值增删。唯一锁死的只有视频类型与风格；换 `T` 只重算数量与时间码。

不复述具体画面，只保留结构功能：

| 段 | 时间（35 秒示例；按 `T` 换算） | 镜数（按总镜数分配） | 功能 | 景别与主体 | 色彩任务 |
|---|---|---|---|---|---|
| A 定场 | 0–6s | 2 | 单人 + 圆形道具建立尺度与主色 | 中近景，人物占 2/3 | 主色首次铺满九宫格，出现轮廓光 |
| B 关系 | 6–14s | 3 | 两三人共同动作建立场所 | 中景，2–3 人横向铺开 | 主色进入服装、织物、木构与地面 |
| C 质感 | 14–22s | 3 | 手部 / 织物 / 水面 / 器皿特写 | 特写，焦段偏长 | 材质反光差异出层次，冷暖交界 |
| D 动作高潮 | 22–31s | 3–4 | 多人 + 水花或扬撒颗粒 + 逆光 | 中景与近景交替 | 空气尘光把主色送进背景空隙 |
| E 收束 | 31–38s | 2 | 单人逆光近景 + 前景花枝 + 光晕 | 中近景 | 低彩度浅主色收尾，高光柔化 |

节奏规则：单镜按用户给定区间（建议 2–4 秒，可改）；相邻镜不重复同一景别；无对白、无字幕叙事；靠动作、色场与光推进，不靠情节反转。

## 2. 脚本写作规则

- 每镜**一句话**，只写可见动作、物件与构图，不写情绪、意境、风格形容词。
- 每镜必须标注：1 个圆形锚点、1 处 10–30% 失焦前景、主色占比目标、光位。
- 只写 1 个可完成动作；动作跨镜连续时，后一镜从上一镜结束姿态起。
- 换主色只允许发生在段落交界；段落内部保持同一主色族。
- **不用大远景、远景、大全景（v5.1 二次纠偏）**：景别只在全景、中景、中近景与过肩、近景、特写、俯拍、微距之间拉开；用户要多人物与拉开景别时同样不越过全景这一档。不做纪念碑式空镜头，不安排航拍、口播或字幕讲解。
- 输出为表格 + 可复制提示词 ID，不写散文式脚本。

## 3. 分镜表字段

| 字段 | 填写内容 |
|---|---|
| 镜号 | S01…S15 |
| 段落 | A / B / C / D / E |
| 时长 | 2–4 秒 |
| 景别 / 焦段 | 中近景 50–85mm / 中景 35–50mm / 特写 85–135mm |
| 主体动作 | 一句可见动作 |
| 圆形锚点 | 具体物件 + 位置 |
| 前景遮挡 | 物件 + 占比 + 失焦 |
| 留白 / 空气面 | 位置 + 带何种颜色 |
| 主色 / 辅色占比目标 | 例如 65% / 20% |
| 光位 | 高位斜后侧（左或右）+ 弱暖补光 |
| 三层 | 前景—人物—远景各自状态 |
| 提示词 ID / 参考图 ID | **默认 v3.8**：P01 / `ROLE_SHEET_X` + `FACE_CLOSE_X`（每位出镜角色成对）/ 〔可选〕`SCENE_REVERSE_0X` / `COLOR_CARD_01`（**仅视频【参考绑定】**，由 A08 成品出图提示词生成）/ `STANDARD_FRAME_01`；扩展定妆包才用 ROLE_REF_01 / ROLE_TRIVIEW_01 / ROLE_BOARD_01 / FACE_CLOSE_01 |
| **生成条 ID** | U01 / U02…，来自 `generation_plan.json` 的 `units[].shot_ids` |
| **生成条时长 / 模型单次上限** | 例如 30s / 30s（Seedance 2.5）、8s / 8s（Veo 3.1） |
| **时间码 beat** | 该镜在生成条内的相对区间，例如 `12.5–15s S06` |
| **使用步骤** | 该镜所属生成条要传哪些参考、选几秒档、生成几次 |
| 备注 | 高难度材质、需补拍等 |

空表见 @assets/shot-list-template.csv。

### 两级结构：成片镜头 vs 生成条

| 概念 | 定义 | 随模型变？ |
|---|---|---|
| **成片镜头（行）** | 分镜表的一行，时长按用户给定区间（建议 2–4 秒，可改） | 否 |
| **生成条（组）** | 一次提交给视频模型的生成，≤ 模型单次上限且落在允许档位 | **是** |

分镜表按镜号排序，但用「生成条 ID」列把相邻镜头分组。同一生成条里的每镜要写成时间码 beat（每 beat 一个可见动作 + 切镜显式声明），剪辑时再按用户给定区间切回短镜头。**长上限不等于长镜头**：Seedance 2.5 的 30s 一条里要写 12 个 beat，而不是一个 30 秒动作。

## 5. 从脚本到提示词的映射

1. 从分镜表取「主体动作」→ 提示词 ①。
2. 从色场方案取主色、辅色、浅主色载体 → ②。
3. 从「圆形锚点 / 前景遮挡 / 留白」→ ③。
4. 从「光位」+ 三层 → ④⑤，按 @references/visual-grammar.md 补齐肤色、抬黑与奶油金高光。
5. 固定引用参考图 ID（**人物两类成对 + 场景反打（可选） + 色卡在【参考绑定】为第二处使用 + 首帧**），写明继承/不继承；色卡进 A 段场景图取色彩方案（A00 母版 / 首帧 / 人物资产除外），摄影母版是文字块不进上传序列；【禁止项】一律写正向句 → ⑥。
6. 生成后按 @references/color-system.md 的验收清单逐镜过，不达标先改首帧与调色。

## 6. 剪辑、调色与声音

- **剪辑**：硬切为主，段落交界可用 1 个 0.5 秒柔化叠化；不做转场特效。每镜按用户给定区间（建议 2–4 秒，可改），宁短勿拖。
- **调色**：全片一套 LUT；抬黑到保留纹理，压高光到奶油金，统一阴影色偏（暖主题偏蓝绿、冷主题偏棕褐）；最后加轻微柔光 / 光晕，不在生成阶段逐镜加。
- **声音**：无对白。环境音（水、织物、炭火、风）+ 一段克制配乐；动作点给轻微音效，不铺满。
- **成片交付**：先出 1080p 版做色场验收，通过后再升分辨率或超分。

## 7. 验收顺序

1. 逐镜看三层、圆形锚点、失焦前景、肤色与轮廓光。
2. 全片连看，检查主色是否跨镜稳定、段落交界是否跳色。
3. 运行 `scripts/color_field_audit.py` 量化主色占比、九宫格覆盖、明暗分布。
4. 缩到缩略图检查脸与手是否仍可定位。
5. 不达标时按「首帧 → 提示词 → 调色 → 模型」的顺序修正，不跳步。

## 8. 按模型调整分镜表（v3：时长上限驱动）

**`generation_plan.json` 里用户给定的 `T`、镜数与单镜区间优先于本模板的一切示例数字**（13–15 镜 / 2–4 秒 / 35 秒都只是示例）。运行 `model_adapter.py --duration <T>` 后按下表重排；下表列的是 `T=35` 的示例结果，换 `T` 要整表重算：

| 视频模型 | 单次上限 | 示例 35s 成片镜数（按 `T` 重算） | 每镜秒数 | **生成条** | 每条装几镜 | 分镜表新增内容 |
|---|---|---|---|---|---|---|
| Seedance 2.5 / Wan 3.0 | 30s | 14 | 2.5 | **2**（30+5） | 12 / 2 | 12 段时间码 beat、返回末帧续接、局部重绘说明 |
| Seedance 2.0 / Kling 3.0 | 15s | 14 | 2.5 | **3**（15+15+5） | 6 / 6 / 2 | `@` 参考绑定列或 Shot N 标注 |
| Runway Gen-4.5 | 10s | 14 | 2.5 | 4 | 4 | 正向-only 约束列（无负向词） |
| Veo 3.1 | 8s | 16 | 2.19 | **5**（8×4+4） | 3–4 | 纯名词负向列、末条裁剪 1s 说明 |
| 海螺 2.3 | 6/10s | 16 | 2.19 | 6 | 3 | 近景限定、分辨率与时长互斥说明 |

其他不变项：单图输入填「标准首帧」列；多图参考逐镜列参考图 ID；9:16 改留白方向；带原生音频加音频约束列（无对白）；彩色段落交界仍只在段界换主色。

调整后仍须满足：用户给定的段落结构与镜数、无对白、相邻镜不重复景别、每镜 1 个圆形锚点 + 1 处失焦前景、**每条生成时长 ≤ 模型上限**。分镜表在 S4 单独交付并等待确认，使用步骤见 @references/usage-guide.md，阶段规则见 @references/staged-delivery.md。
