# 角色设计：参考原片、好看、但不千篇一律（S0 定稿 · S3 出图前自检）

> 本文件回答一件事：**怎么把「参考原片、要好看、别撞脸」变成能写进提示词的具体项**。空喊「东方美学 / 电影感 / 高级感」必然生成同一张 AI 网红脸。
> 适用范围：`[角色固定描述串]`、`FACE_QUAD_01` 面部四宫格、`ROLE_REF_01` 定妆基准，以及所有角色相关提示词。**不约束色场、光影与分镜**（那些在 `visual-grammar.md` / `color-system.md`）。
> 与 `character-sheet-spec.md` 的关系：这份管**脸与整体美感设计什么**，那份管**用什么规格拍出来**；服装的形制、层次、材质、四朝向结构单独见 `costume-design.md`。三份一起才构成完整的角色设计。

## 1. 「参考原片」到底参考什么：三取三不取

原片只作拆解参考，不可直接商用。取的是**设计方法**，不是人物本身。

| ✅ 取（方法层） | ❌ 不取（结果层） |
|---|---|
| 人物与环境的**尺度关系**：人物是唯一尺度基准，道具 1–2 头宽，建筑 1.5–3 倍人高 | 原片里具体那张脸、那个演员、那个发型 |
| **妆造与身份的匹配逻辑**：妆容服务于年代与劳作身份，不服务于「上镜」 | 原片的具体服装款式、纹样、配色组合 |
| **材质的真实感做法**：粗棉 / 丝 / 纱 / 金属至少两种反射率相邻，皮肤有纹理不磨皮 | 原片的具体构图、动作、道具与台词 |
| 低彩度大面积 + 小面积高彩度点睛的**配色秩序** | 原片主色本身（新片主色由 S0 另定） |
| 一处**生活痕迹**（袖口微皱、一缕碎发、织物磨边）带来的可信度 | 00:40 之后的主持人、教程 UI、字幕页与讲解回放片段 |
| 「人从属于环境、不压过环境」的**表演与取景分寸** | 把原片画面直接垫图 / `--sref` / 图生图复刻 |

> 落地检查：把参考原片之后写出的描述串念一遍，若其中任何一项能在原片画面里被指出来（「就是那件蓝袍子」），删掉重写；若只能指出「做法」（「用粗棉配铜器形成反射率对比」），合格。

## 2. 「好看」的可执行锚点（六项，逐项落进描述串）

| 锚点 | 具体做法 | 写进提示词的样子 |
|---|---|---|
| ① 比例秩序 | `body_ratio` 全包锁定；肩线水平、颈肩关系清楚；三庭五眼不做夸张位移 | `8 头身，身材修长但比例自然，肩线水平` |
| ② 骨相具体 | 脸型、眉骨、鼻梁、下颌、眼型要写成**类型与形状**，不写「精致 / 好看 / 绝色」 | `鹅蛋脸、眉骨平缓、鼻梁中等高度、眼型偏细长` |
| ③ 三处记忆点 | **主识别特征**（发饰 / 领型 / 随身器物）+ **材质对比** + **一处不对称细节**，三项缺一不可 | `素色发带压低髻 / 粗棉袍配铜秤盘 / 右袖口比左袖口多一道挽边` |
| ④ 材质对比 | 至少两种反射率不同的材质相邻，写明漫反射或反光方式；服装部分按 `costume-design.md` 六维表展开 | `粗棉漫反射 + 铜器窄高光 + 半透纱` |
| ⑤ 配色秩序 | 低彩度大面积 + 小面积高彩度点睛；点睛色与 S0 主辅色体系一致 | `靛蓝棉袍大面积低彩度，烛金发绳小面积点睛` |
| ⑥ 一处不完美 | 留生活痕迹，破掉 CG 的完美感 | `一缕碎发落在鬓角、袖口有自然压皱` |

**不做什么比做什么更重要**：不磨皮、不套网红滤镜妆、不写真摆拍、不做「大片感」排版。真实质感本身就是美感来源——这也是 `character-sheet-spec.md` §4.2 要求「无现代浓妆 + 真实皮肤纹理 + 低密度黑柔」的原因：黑柔负责去掉数字硬锐，纹理负责留住人味。

## 3. 反千篇一律的硬规则

1. **禁止模板词进描述串**：`通用古风 / 仙侠白纱 / 汉服小仙女 / 国风少女 / 影楼写真 / 电影感美人 / 精致五官 / 绝美容颜 / 网红脸 / 超模脸`。
2. **禁止标准件长相**：锥子脸、欧式平行大双、克隆高鼻梁、微笑唇、无瑕磨皮脸、统一空气刘海、同一套发饰。至少一处骨相或发饰要**具体到形状**。
3. **每个主题重写描述串**：不复用上一主题的 `[角色固定描述串]`；换了主题还沿用同一串，等于换了背景没换人。
4. **差异化清单 ≥3 条**：每角色写 3 条以上「具体到物件 / 形状 / 颜色」的识别项；多角色之间至少 2 项不同（脸型类型、发饰结构、领型或材质对比任选）。
5. **反 reroll 依赖**：出图撞脸时不靠多抽几次碰运气，先回到第 2 节补记忆点、改骨相描述、加不对称细节，再重出。
6. **四个朝向都要成立**：`FACE_QUAD_01` 的左 90° / 右 90° / 背 180° 必须有可描述的头部结构（耳后发髻、发饰背面、颈后发际线）；服装同样要有 `costume-design.md` 的四朝向结构清单。只有正面好看的设计，一到侧背镜头就崩。
7. **后面每张定妆图都要对应**：`ROLE_REF_01`、三视图、四格板、单图都必须显式引用 `FACE_QUAD_01` 的某一格，并同规格、同妆造、同服装（§4.4 对应性矩阵）。不许四宫格自成一套、定妆图另画一张脸。

## 4. 同质化自检 6 问（S3 出图前必过，任一命中就重写描述串）

| # | 问题 | 命中后改什么 |
|---|---|---|
| 1 | 描述串里有没有上一主题或原片的具体人物 / 服装？ | 换成方法层描述，删掉可指认的具体项 |
| 2 | 三处记忆点是否齐全，且都能画成可见物件？ | 补主识别特征 / 材质对比 / 不对称细节 |
| 3 | 有没有模板词或现代浓妆词？ | 删模板词，妆容改「符合时代与身份的清淡妆造」 |
| 4 | 换个角色 / 换个主题后，这段描述还成立吗？若成立说明太泛 | 加入只属于本主题的身份、职业与器物 |
| 5 | 侧 90° 与背 180° 有没有明确结构可依据？ | 补发髻、发饰背面、领口背面结构 |
| 6 | 生成的四宫格是否像「同一套 AI 脸换了角度」？ | 改骨相类型与一处不对称细节后重出，不靠 reroll |

## 6. S0 要写进 `master_overview.md` 的角色设计字段

| 字段 | 内容 | 谁来定 |
|---|---|---|
| `[角色固定描述串]` | 脸型骨相 + 妆造 + 发饰 + 服装形制 + 鞋履，逐字锁定 | S0 定稿，S3 一个字不改 |
| `body_ratio` | 7.5–8（写实）/ 8.5–9（古装风格化） | S0 |
| 三处记忆点 | 主识别特征 / 材质对比 / 不对称细节 | S0 |
| 差异化清单 | ≥3 条，多角色之间 ≥2 项不同 | S0 |
| 一处生活痕迹 | 具体到物件（袖口压皱 / 一缕碎发） | S0 |
| 面部规格模式 | `unified`（默认）/ `layered`；黑柔档位 1/8 或 1/4 | S0 记入 theme_brief，S3 执行 |
| 服装六维 + 四朝向结构清单 | 见 `costume-design.md` §1 / §2，逐字写进描述串 | S0 |

> 这些字段不进 `master_overview.md` 的「摄影设定 / 色彩氛围」，放在「美学设定 · 人物」子表里；S0 阶段仍**不出现模型名、提示词与分镜表**。
