# 角色参考包规范 v3.6：附录 A 为默认精简规格 / 正文为扩展定妆包

> **适用范围先读这一句（v3.6 / v5.2 定稿版式）**：**默认走附录 A**——每位角色 1 张 `ROLE_SHEET_X` 上下分区定妆板（上 1/3 正侧面面部特写 + 下 2/3 放大裁头正面服装图与背面全身，出图提示词逐字采用用户定稿）；本文正文（面部四宫格 + 四张面部单图 + 定妆基准 + 朝向三视图 + 四格板 + 服装放大 + 13 项验收）是**扩展定妆包**，只有用户主动要求「完整定妆包 / 全部多视图」时才启用。输入模式（`M0 零素材` / `M1 部分素材` / `M2 已有资产`）决定前两格素材怎么来，见 @references/input-modes.md（唯一权威）。
> 本文件是**角色参考图的唯一权威定义**。所有 `references/` 与 `assets/` 里出现 `FACE_QUAD_*`、`ROLE_REF_*`、`ROLE_BOARD_*`、`FACE_CLOSE_*`、`ROLE_SHEET_*`、`三视图`、`四宫格`、`定妆` 的地方，都以本文件为准。
> 适用阶段：S3（角色设计自检在 S0 就要定）。适用对象：图像模型产出的**角色参考资产**，不适用于 `STANDARD_FRAME_01` / `SCENE_REF_*` / `COLOR_CARD_01` / 逐镜视频画面。
> 版本：skill v3.6.0；正文内容源自 v3.3.0。
> 角色设计为什么好看、为什么不千篇一律，见 @references/character-design-aesthetics.md；**服装造型设计见 @references/costume-design.md**；可复制提示词见 @assets/character-sheet-prompts.md。
> 本版所有「对应」要求汇总在 §4.4：四宫格是身份锚，后面每一张定妆图都必须能指回它的某一格。

## 0. 本版相对 v3.2 改了什么（以及为什么）

| 用户新指令 | 处理 | 原因 |
|---|---|---|
| 「人物头部特写四宫格，同一张图分为四个等分格子：正面、左侧面、右侧面、背面，面部特写」 | **新增 `FACE_QUAD_01`**：2×2 四等分、四格全为头部特写、正 0° / 左 90° / 右 90° / 背 180°；另拆出 `FACE_CLOSE_01..04` 四张面部单图 | 原包只有 1 张正面 + 1 张侧面脸，左侧 / 右侧 / 后脑发饰没有依据，侧背近景最容易崩发饰与耳后结构 |
| 「在最开始还要生成一个面部特写的四视图」 | **S3 生成顺序整体重排**：`FACE_QUAD_01` 成为**第一张**，身份链改为 `FACE_REF_01 → FACE_QUAD_01 → ROLE_REF_01 → 其余` | 先锁死四个朝向的五官与妆造，再让全身基准图以它为面部依据；反过来做会让后续所有图沿用一张脸的随机偏差 |
| 「角色设计要参考原片，一定要有美感，要好看，但是又不能千篇一律」 | **新建 `character-design-aesthetics.md`**：三取三不取、美感可执行锚点、三处记忆点、差异化清单、同质化自检 6 问；S0 定清单、S3 出图前先过自检 | 「好看」必须落到脸型类型、材质对比、不对称细节、生活痕迹；空喊风格词必然生成 AI 网红脸 |
| 「无现代浓妆」 | 写进**面部层正向约束 + 统一负向清单** | 现代眼线 / 假睫毛 / 修容高光 / 咬唇会瞬间把古装或年代题材拉成影楼写真 |
| 「105mm 镜头」 | 面部 / 头部特写**统一 105mm 等效长焦**；全身仍 85mm 以上等效或正交 | 长焦压缩、无透视畸变，五官比例在四格之间才可比；广角会把正面与侧面拍成两张不同的脸 |
| 「Tiffen 黑柔滤镜」 | **Tiffen Black Pro-Mist 1/8（默认）/ 1/4（上限）低密度黑柔**，全包统一档位 | 让高光轻微晕散、对比略降，去掉数字硬锐感；但必须写死「不是柔焦 / 不是景深虚化 / 不是雾感 / 不是场景光晕」，五官边缘与织纹仍要可辨 |
| 「纯色暖灰背景」 | 默认 `unified`：整套参考包统一**纯色暖灰 `#C6BCB1`**；可选 `layered`：面部层暖灰、全身层回中性灰 `#B8B8B8` | v3.2 的中性冷灰符合「基准」但出图偏冷硬；暖灰低饱和、不改变固有色，画面更耐看。两套规格绝不能混在同一批图里 |
| 旧规范的「无光晕 / 全画面清晰」 | **改写边界**：禁的是场景光晕、镜头炫光、柔焦、散景、失焦前景与景深虚化；低密度黑柔造成的高光晕散是**光学滤镜效果，允许且要求** | 不区分这两者，模型会要么把图做成硬锐证件照，要么糊成一层雾 |
| 「三视图」/「四视图」命名 | 再正名一次：`FACE_QUAD_01` = **面部四宫格（四个朝向的头部特写）**；`ROLE_TRIVIEW_01` = **全身朝向三视图**；`ROLE_BOARD_01` = **四格定妆板（排版）** | 三者是不同资产，任何一张都不能替掉另一张 |
| 「包括后面的人物定妆图也要对应」 | 新增 **§4.4 对应性矩阵** + 第 13 项验收：`FACE_QUAD_01` 是唯一的脸与头部结构锚，后面每张图都必须写明引用它哪一格；同规格、同妆造、同光位、同 `body_ratio` | 四宫格只自己好看没用；定妆图另画一张脸，整个身份链就断在第一步 |
| 「服装造型设计也要思考一下」 | 新建 **@references/costume-design.md**：形制 / 层次 / 材质 / 配色与色场接口 / 配饰与圆形锚点 / 不对称与生活痕迹六维，四朝向服装结构清单，反模板与自检 6 问，可粘贴段 | 服装是主色进入画面的最大载体；只锁脸不锁服装，成片色场没有落点，且最容易滑进通用古风模板 |

**结论**：v3.3 的参考包 = 一张面部四宫格（最先出）+ 一张全身定妆基准 + 一套朝向三视图 + 一块四格定妆板 + 六张拆出的单图。用户给的定妆 / 四视图提示词一般只是**版式与质感要求的来源**，可优化；**例外（v5.2）**：用户明确指定「四视图提示词用这个」时，该条是默认 `ROLE_SHEET_X` 的定稿出图提示词，**逐字采用、不改写**（附录 A.1 / @assets/character-sheet-prompts.md §14.6）。本节正文其余内容仍只适用于用户主动要求的**扩展定妆包**。

## 1. 一句话规则（**本节以下至 §15 全部只适用于扩展定妆包**；默认规格见附录 A）

**先出 `FACE_QUAD_01` 面部特写四宫格（四等分：正面 / 左侧 90° / 右侧 90° / 背面 180°，全为头部特写）锁死四个朝向的五官与妆造；再出纯色暖灰影棚、三点式 5500K 中性白还原光、105mm 面部 / 85mm+ 全身、低密度 Tiffen 黑柔、无现代浓妆、全身正面头到鞋完整的写实定妆基准；另外必产朝向三视图、四格定妆板与六张单图。后面每一张定妆图都必须按 §4.4 对应回四宫格的某一格，服装造型按 `costume-design.md` 的六维与四朝向清单锁定，全包同一规格同一身份。**

色场、主色光、暖金轮廓光、前景遮挡、留白、中浅景深、柔焦、剧情动作、复杂场景**一律不进角色参考包**，它们属于成片画面。

## 2. 为什么要分开（写给用户，也写给模型）

| 如果参考图带这些 | 后果 |
|---|---|
| 场景、庭院、门框、檐帘 | 换场景时旧背景被一起带进新镜头 |
| 彩色光 / 暖金色光 / 强氛围光 | 服装固有色被染色，色卡与统一 LUT 失去基准，色场锁死 |
| 方向性强的造型主光被当成人物属性 | 每个镜头出现同一道光，侧面与背面机位光位错乱 |
| 半身 / 七分身 / 裁脚 | 模型没见过腿、鞋、下摆，全身与群像镜头必崩 |
| 只有正面一张脸 | 转身、侧身、背对机位没有外观依据，只能靠猜 |
| **没有面部四宫格** | 左侧 / 右侧脸型不对称、耳后与后脑发髻结构漂移，侧背近景崩发饰 |
| 只有远景全身、没有面部特写 | 近景五官崩坏、妆造漂移 |
| 头身比在不同图里不一致 | 跨镜头人物忽高忽矮、头忽大忽小 |
| 磨皮 / 塑料皮肤 / 大片感排版 / 现代浓妆 | 全片出现 AI 油腻感与影楼感，写实与时代质感同时丢失 |
| 广角拍脸 / 四格用不同焦段 | 正面与侧面像两个人，四宫格失去比对价值 |
| **四宫格与定妆图不对应**（各画一张脸 / 背面另画发髻 / 左右不对称细节换边） | 身份链断在第一步，后面所有一致性手段都失效，侧背镜头必崩 |
| **服装只写「古装 / 长袍 / 仙气」** | 主色没有落点、四朝向结构空白、成片滑进通用模板，见 `costume-design.md` |

**职责划分**：`FACE_QUAD_*` / `FACE_CLOSE_*` 只回答「这张脸与妆造从四个方向看长什么样」；`ROLE_REF_*` / `ROLE_BOARD_01` 回答「这个人穿什么、什么比例、背面什么样」；`COLOR_CARD_01` 回答「片子是什么颜色」；`STANDARD_FRAME_01` 回答「这个颜色 + 这道光落在这个人和场景上是什么样」。四者不能互相代替。

> **关于黑柔与轮廓光的折中**：允许**中性白、窄边、低强度**的棚拍轮廓光与**低密度黑柔高光晕散**，是因为它们可复现、能去掉数字硬锐感；但必须在视频层绑定句里写死「参考图的光位与滤镜是棚拍还原，一律不继承」，成片主光只由 `STANDARD_FRAME_01` 与逐镜提示词给出。若小样出现「每镜同一道边光」「跨视图光位不一致」「每镜都带一层黑柔雾感」，立即降级到 §5.4 平光 + 无滤镜模式。

## 3. 输入槽位与身份链

| 槽位 | 只提供 | 不提供 |
|---|---|---|
| `FACE_REF_01` | 五官骨相、脸型、妆容、发际线、神态 | 服装、姿态、光线、背景 |
| `OUTFIT_REF_01` | 服装形制、面料、层次、纹样、鞋履、配饰 | 五官、体型、光线、背景 |

- 用户上传了参考图 → 提示词里逐项写 `inherit-nothing-else`；**未提供**则完全由 S0 的 `[角色固定描述串]` 生成，不得虚构「已参考图 1 / 图 2」。
- **默认（附录 A）不要求这两个槽位齐备**：`M0 零素材` 两格都从零生成、`M1` 补缺、`M2` 从已有图裁切；逐位角色判定与补齐规则见 @references/input-modes.md §1–3。
- **身份链（v3.3 改动）**：`FACE_REF_01` + `[角色固定描述串]` → `FACE_QUAD_01`（**面部权威**，四个朝向）→ `ROLE_REF_01`（全身权威）→ 三视图 / 四格板 / 单图 / 标准首帧。后面的图一律引用链上更靠前的图，不得各自从文字重新画一张脸。
- 角色设计的差异化清单必须在 S0 定稿并写进 `[角色固定描述串]`，见 `character-design-aesthetics.md`。

### 4.1 `FACE_QUAD_01` 面部特写四宫格（本版新增，S3 第一步）

| 项目 | 硬规格 |
|---|---|
| 版式 | **同一张图四等分**：默认 2×2，每格占画面 **1/4**、等宽等高、格线对齐、格内人物居中；四格之间留等宽细缝或无缝，不加边框、标题、编号、标注线、装饰 |
| 画幅 | `--ar 1:1`（2×2）；若模型对 2×2 一致性差，改 **1×4 横排四等分** `--ar 4:1`，两种都算合格但一次只选一种 |
| 左上格 | **正面 0°** 头部特写，双眼平视，肩线水平 |
| 右上格 | **左侧面 90°**：镜头看到人物**左半侧脸**（人物面朝画面右侧），exact left profile |
| 左下格 | **右侧面 90°**：镜头看到人物**右半侧脸**（人物面朝画面左侧），exact right profile；与右上格必须互为镜像朝向，不能出成同一张 |
| 右下格 | **背面 180°**：**头部背面特写**（后脑发髻、发饰背面结构、耳后、颈后发际线），不是脸、不是全身 |
| 取景 | 四格**全为头部特写**：头顶到锁骨 / 肩颈上沿，紧凑构图；四格内头部尺度一致，眼位 / 耳位对齐同一水平基线，头顶与下巴都不被格边裁切 |
| 一致性 | 同一人、同一五官骨相、同一妆造、同一发饰、同一 `[角色固定描述串]`、`body_ratio` 逐字写入；四格同一背景色、同一焦段、同一黑柔档位、同一光位 |
| 面部规格 | 严格按 §4.2：无现代浓妆、105mm 等效、低密度 Tiffen 黑柔、纯色暖灰背景 |
| 禁止 | 半身 / 全身、剧情动作、夸张表情、色场光影、景深虚化、散景、失焦前景、现代物件、文字水印 |

> **左右两格最容易出成同一张**：提示词里必须写出「人物面朝画面右侧 / 面朝画面左侧」的方向句，并在验收时逐格比耳位与鼻尖朝向。左右脸允许有轻微自然不对称，但骨相、眉眼、发际线、发饰必须一致。

### 4.2 面部统一规格（用户指定，全包默认）

| 项 | 规格 | 写进提示词的固定句 |
|---|---|---|
| 妆造 | **无现代浓妆**：素颜感或时代相符的淡妆；禁现代眼线、假睫毛、纹绣眉、修容 / 高光棒、咬唇 / 渐变唇、浓腮红、美瞳、美甲、湿发发胶、影楼写真妆、网红滤镜妆 | `妆容为符合时代与身份的清淡妆造，无现代浓妆` |
| 镜头 | **105mm 等效长焦人像镜头**，压缩透视、五官不拉伸、无广角畸变；全身图仍用 85mm 以上等效或正交 | `105mm 等效长焦人像视角，无透视畸变` |
| 滤镜 | **Tiffen Black Pro-Mist 1/8（默认）/ 1/4（上限）低密度黑柔**：高光轻微晕散、对比略降、暗部保留纹理、五官边缘与织纹仍清晰可辨；全包使用同一档位 | `Tiffen Black Pro-Mist 1/8 低密度黑柔滤镜效果：仅高光轻微晕散、对比略降` |
| 背景 | **纯色暖灰 `#C6BCB1`**（允许 `#BFB4A8`–`#CDC4B9`）无缝影棚，单色无渐变、无地面接缝、无投影、无场景道具；暖灰是背景色，**不改变肤色与服装固有色** | `纯色暖灰 #C6BCB1 无缝影棚，单色无渐变` |
| 白平衡 | 三点式灯光仍全部 **5500K 中性白**；暖灰背景与黑柔都不改变色温，不把皮肤染暖 | `三盏灯 5500K 中性白，暖灰背景不改变肤色与服装固有色` |

**四个必须写死的「不是」**（否则模型会糊成一片）：
`低密度黑柔 ≠ 柔焦 / ≠ 景深虚化 / ≠ 散景或失焦前景 / ≠ 雾感与场景光晕或镜头炫光`。全画面清晰，眉眼、碎发、织纹、缝线仍可逐项辨认；禁的是**场景光**，允许的是**滤镜对高光的作用**。

### 4.3 两层规格的桥接、开关与降级

默认 **`unified`（整套统一）**：`FACE_QUAD_01`、四张面部单图、`ROLE_REF_01..03`、三视图、四格板**全部**用暖灰 + 三点式中性光 + 105mm（头）/85mm+（身）+ 同一档黑柔 + 无现代浓妆。这是默认，因为一套图里出现两种背景 / 两种滤镜会让模型判定为两个人。

可选 **`layered`（分层基准）**：仅当「模型把暖灰染进服装固有色」或「黑柔糊掉织纹」时启用 —— 面部层用 §4.2 全套；全身基准层回到中性灰 `#B8B8B8` + 85mm 以上等效或正交 + **不写黑柔**。切换靠 `model_adapter.py --face-spec layered`，**整套一起切**，并在 QA 表记录，禁止只改其中一张。

- 无论哪种模式，`COLOR_CARD_01` / `SCENE_REF_*` / `STANDARD_FRAME_01` **永远不带影棚背景与黑柔**；成片若要黑柔，在剪辑层对全片统一加一次，不逐镜加。
- 视频层必须写死：暖灰背景、105mm 透视、黑柔高光晕散与三点式光位**一律不继承**（见 §14）。
- 出现「每镜同一道边光 / 跨视图左右明暗断层 / 轮廓光变暖金 / 每镜蒙一层雾」任一情况 → 整套降级到 §5.4 平光 + 无滤镜模式，并把四宫格与所有单图一起重出。

### 4.4 对应性矩阵：`FACE_QUAD_01` 是后面所有定妆图的身份锚

**四宫格不是一张孤立的漂亮图。`ROLE_REF_01`、三视图、四格板、六张单图、标准首帧、每一条逐镜提示词都必须能指回它的某一格，并逐项一致。** 每条提示词里要显式写出引用关系（例：`面部严格以 @FACE_QUAD_01 左上格为准`），不写就是不合格。

| **左下 右侧 90°** | `FACE_CLOSE_03`、右侧机位与镜像侧面 | 与右上格互为镜像朝向；右袖挽边、右侧腰饰等不对称细节必须与 `[角色固定描述串]` 写明的那一侧一致，不能左右互换 |

## 5. 光照规范：三点式中性还原光

### 5.1 固定光位（所有参考图逐字一致）

| 灯位 | 位置 | 作用 | 强度 |
|---|---|---|---|
| 主光 Key | 人物**正左侧** 45° 高位 | 照亮面部与服装主体 | 中等，柔光箱 |
| 辅光 Fill | 人物**正右侧** 45° 同高 | 补暗部，保留纹理 | 主光约 1/2–1/3，柔光箱 |
| 轮廓光 Rim | 人物**后右侧** 高位 | 分离人物与暖灰底，勾出发丝与衣缘 | 低强度、窄边、柔光 |

### 5.2 硬约束

- 三盏灯全部 **5500K 中性白平衡**，无彩色光、无暖金 / 烛火 / 靛蓝色光、无强氛围特效；暖灰背景是背景色，不是色光。
- 光线**均匀干净**：面部、发型、服装质感、身形线条都清楚，暗部不死黑、高光不溢出到纯白、无造型性投影、无镜头炫光。低密度黑柔造成的**高光轻微晕散是允许且要求的**，它不是场景光晕。
- 背景为**纯净暖灰 `#C6BCB1` 无缝影棚**（`layered` 模式的全身层用 `#B8B8B8`），单色无渐变、无地面接缝、无投影、无场景、无道具。
- 全画面清晰，无景深虚化、散景、柔焦、失焦前景、空气透视；黑柔不降低五官与织纹的可辨度。
- 面部 / 头部特写 105mm 等效，全身 85mm 以上等效或正交，四格板内所有格同一焦段口径。

### 5.3 视频层必须写的一句

`参考图中的三点式光位、暖灰影棚背景、105mm 透视与 Tiffen 黑柔高光晕散都是棚拍还原，不属于人物属性；@FACE_* / @ROLE_* 一律不继承任何光位、光比、背景色与滤镜效果。成片主光只由 @STANDARD_FRAME_01 与逐镜提示词给出。`

### 5.4 降级：平光 + 无滤镜模式（flat mode）

出现以下任一情况，把**整套参考包**的光照改为「均匀漫射平光、5500K 中性白平衡、无方向性阴影、无轮廓光、不写黑柔滤镜」，并同步重出四宫格：

1. 小样里每个镜头都出现同一道窄边光；
2. 跨视图光位左右不一致，拼版出现明暗断层；
3. 模型把轮廓光渲染成暖金色 / 发光边，或把黑柔渲染成整屏雾感；
4. 使用的是对风格继承特别敏感的模型（Midjourney、部分开源 checkpoint）。

平光模式与三点式 + 黑柔模式**不能混在同一套参考包里**，改就整套一起改，并在 QA 表记录。

## 13. 生成顺序（**扩展包** S3 必做，不能颠倒；默认规格的顺序见附录 A.2 / `input-modes.md` §2.1）

1. **角色设计自检**：按 `character-design-aesthetics.md` 过 6 问，定稿 `[角色固定描述串]` 与差异化清单；确认 `FACE_REF_01` / `OUTFIT_REF_01`、`body_ratio`、`face_spec` 模式（unified / layered）与黑柔档位。
2. **出 `FACE_QUAD_01` 面部特写四宫格**（**第一张图，先于任何全身图**）：以 `FACE_REF_01` + 描述串为依据，出 4 张挑 1；逐格核对四个朝向、四等分、无现代浓妆、105mm、暖灰、低密度黑柔。锁定后把 `[角色固定描述串]`、`body_ratio`、黑柔档位逐字记进 QA 表。
3. 拆出/另出 `FACE_CLOSE_01..04` 四张面部单图，与四宫格对应格逐项一致。
4. 出 `COLOR_CARD_01`（纯色卡，独立文件，不带人物、场景与黑柔）。
5. 出 `ROLE_REF_01` 定妆基准图，出 4 张挑 1；**面部严格以 `FACE_QUAD_01` 正面格为准**。
6. 以 01 为唯一身份依据，出 `ROLE_REF_02`（正侧 90°）、`ROLE_REF_03`（背 180°），拼成 `ROLE_TRIVIEW_01`。
7. 出 `ROLE_OUTFIT_DETAIL_01`（放大服装图），按 §9.3 检查，必要时降级。
8. 把 `FACE_CLOSE_01/02` + 服装放大图 + 背面全身按 1/3 : 2/3 拼成 `ROLE_BOARD_01`；或让模型一页出四格后再拆单图，二者取其一但**必须同时有拼版和单图**。
9. 出 `SCENE_REF_01..03`（场景空镜，**这里才带色场与成片光影**）。
10. 用四宫格 + 01 + 三视图 + 定妆板 + 色卡 + 场景空镜，二次合成 `STANDARD_FRAME_01`（**这一步才加高位斜后侧光、暖金轮廓光、前景遮挡、留白、中浅景深**）。
11. 视频层上传顺序：`COLOR_CARD_01` → `STANDARD_FRAME_01` → `ROLE_TRIVIEW_01` → `ROLE_BOARD_01` → `ROLE_REF_01` → `FACE_CLOSE_01` → `SCENE_REF_01`，逐项写明继承什么、不继承什么；`FACE_QUAD_01` 留作身份校验，参考图位充足时再上传。

### A.4 零素材特别条款

没有用户图时，身份锚由 `ROLE_CHARTER_X`（12 项文字设定）承担：脸型骨相 / 眉眼鼻唇 / 发际线与发饰背面结构 / 妆造 / `body_ratio` / 服装六维 / 四朝向结构清单 / 三处记忆点 / 差异化清单 ≥3 / 生活痕迹 / 固有色 HEX / 不对称所在侧。**三禁**：不写「@参考图 1」这类虚构引用；不把第一张随机出图当权威（出 4 挑 1 再锁定）；不在同批图里改描述串、比例、发饰或 HEX。零素材建议先出 `ROLE_STILL_X`，把脸与服装锁进同一张全身图再拼板，可明显降低串脸率。

### A.5 为什么可以精简

六类实例彼此都是同一张脸的重复描述。上传得越多，模型越容易在多个「略微不同」的脸之间挑错，反而放大串脸风险；单张拼板把身份、三视结构、服装结构一次性锁在同一张图里。**最终人物资产永远只有一张**；视频上传序列是「每位出镜角色 1 张拼板 + 1 张人脸特写」两类成对，除此之外过程图一张不挂——这两件事必须分开。

### A.6 降级

串脸 → 逐格单独生成再拼回**同一上下分区版式**；比例反复漂 → 先出 `ROLE_STILL_X` 再回拼板；左下裁头不干净 / 人物太小 / 手脚被裁 → 重跑并保留「只许裁头不许裁手脚」「禁止人物显得太小」原句；背面不完整 → 重出右下格；材质画错 → 补 `FABRIC_DETAIL_X`；零素材文字锚太虚导致每张脸都不同 → 回 S0 补 12 项设定，不要靠 reroll 硬救。
