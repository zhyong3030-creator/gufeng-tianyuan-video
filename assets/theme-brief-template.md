## 三、规格（写进 S0 总揽 · **项目参数，不卡死**）

> **唯一锁死的只有视频类型与风格**。下面每一项都由用户在 S0 给定；用户没给才用括号里的建议值，并在总揽标注「建议值，可改」。改任一项只需 S2 重算生成条、S4 重排分镜表与时间码，**色场、光位、肤色、质感、六块结构与参考绑定一律不变**。

- **成片时长 `T`**：`[用户给定；建议 35 秒（可改）]`，例如 15 / 40 / 60 / 90 秒都照做
- **镜头数 / 场景数**：`[用户给定；建议 13–16 镜 / 6 场景（可改）]`
- **段落数**：`[用户给定；建议 5 段（可改）]`，结构功能位按段数增删
- **单镜时长区间**：`[用户给定；建议 2–4 秒（可改）]`（**成片镜头，不等于生成条**）
- **画幅 / 分辨率 / 帧率**：`[建议 16:9 / 720p 小样、1080p 成片 / 24fps，均可改]`
- **对白 / 声音**：`[建议无对白；环境音 + 一段克制配乐，可改]`
- **段落结构**：`[按用户给定段数；5 段示例：A 定场 / B 关系 / C 质感 / D 高潮 / E 收束]`，时间分配按 `T` 换算，见 `assets/overview-template.md`

## 四、生产条件（**S1 才询问**）

- **人物资产模式**：（**默认精简 v5.2：每人 1 张 ROLE_SHEET_X 上下分区定妆板**，上 1/3 正侧面面部特写 + 下 2/3 放大裁头正面服装图与背面全身，出图提示词逐字采用用户定稿 / 用户主动要求时才用完整角色参考包）
- **视频人物参考**：（**默认每位出镜角色两类成对：`ROLE_SHEET_X` + `FACE_CLOSE_X`** / 扩展定妆包主锚图）；**v5.1**：后景焦外不具名背景人影不占参考位、不出资产
- **意向图像模型**：（例 Nano Banana 2 / GPT Image 2 / Seedream 5 / Midjourney / FLUX.2 / SDXL）
- **是否多模型分工**：否（默认单模型全包）/ 是 → 定基调：＿＿ / 出人物：＿＿ / 锁一致性：＿＿（见 `references/model-selection.md` 4.1）
- **意向视频模型**：（例 Seedance 2.0 / 2.5 / Kling 3.0 / Veo 3.1 / Runway / Wan 3.0 / 海螺）
- **我的推荐**：主推组合 + 备选 + 理由（S1 产出 `model_plan.md` 时填）
- **关键硬约束**（从 `assets/model_profiles.json` 取）：
  - 视频单次最短–最长 / 档位：
  - 参考图上限与绑定语法：
  - 负向词机制 / 原生音频 / 语言 / 状态：
- **生成通道**：A WorkBuddy 内生成 / B 用户外部平台 / C Flova 项目（默认 B）
- **是否可本地 / 开源部署**：默认否
- **预算约束**：默认先小样后批量，不直接开最高分辨率；生成需逐批确认
- **头身比 `body_ratio`**：（写实 7.5–8 头身 / 古装风格化 8.5–9 头身；全包锁定同一数值）
- **角色设计**：`[角色固定描述串]` / 三处记忆点 / 差异化清单 ≥3 条 / 一处生活痕迹；参考原片只取设计方法（见 `references/character-design-aesthetics.md`）
- **服装造型**：六维表 + 正/左 90°/右 90°/背 180° 四朝向结构清单（见 `references/costume-design.md`）
- **输入参考槽位**：`FACE_REF_01`（只给五官骨相与妆造）/ `OUTFIT_REF_01`（只给服装形制与配饰）；未提供则记为假设
- **面部规格模式 `face_spec`**：`unified`（默认，整套暖灰 `#C6BCB1` + 105mm 头/85mm+ 身 + 低密度黑柔 + 无现代浓妆）/ `layered`（面部层暖灰+黑柔、全身层中性灰无滤镜）
- **黑柔档位**：Tiffen Black Pro-Mist 1/8（默认）/ 1/4（上限）；低密度黑柔只让高光轻晕，不是柔焦 / 景深 / 雾感
- **光照模式**：三点式 5500K 中性白还原光（默认）/ 均匀漫射平光 + 无滤镜（降级时整套切换）
- **参考图编号（生成顺序）**：`FACE_QUAD_01`（**第一张**，面部四宫格四等分：正/左 90°/右 90°/背 180°，全为头部特写）/ `FACE_CLOSE_01..04`（四张头部单图）/ `COLOR_CARD_01` / `ROLE_REF_01`（暖灰影棚三点式中性光、105mm/85mm+、低密度黑柔、无现代浓妆、全身正面基准，面部严格对应四宫格左上格）/ `ROLE_REF_02`（正侧 90°）/ `ROLE_REF_03`（背 180°）/ `ROLE_TRIVIEW_01`（朝向三视图拼版）/ `ROLE_BOARD_01`（四格定妆板）/ `ROLE_OUTFIT_DETAIL_01`（放大服装单图）/ `SCENE_REF_01..03` / `STANDARD_FRAME_01`（带色场与成片光影，不带影棚黑柔）。**后面每张图都要写明引用 `FACE_QUAD_01` 哪一格**（§4.4 对应性矩阵）。规范见 `references/character-sheet-spec.md`。
- **推进方式**：默认阶段闸门 S0→S7，一次一步；用户说「全部做完」才连续产出文档

> 选定两层模型后运行：
> `python3 scripts/model_adapter.py --video-model <视频> --image-model <图像> --duration <成片总时长T> --aspect <画幅> --out-dir <项目目录>`
> 换模型 → 回退到 S1 重跑适配与整体规划，S0 总揽保持。

## 六、禁止项

- 不复制参考片的人物、服装、剧情、具体构图与台词；角色设计只取方法、不取可指认的具体项
- 不把低密度 Tiffen 黑柔写进负向清单；不把影棚暖灰背景、105mm 透视与黑柔高光晕散继承进视频层
- 不用未叠加面部统一规格 / 对应性声明 / 服装造型段的旧定妆底稿出图
- 不写入教程界面、访谈、字幕页、讲解中回放片段的美术元素
- 不写「东方美学、电影感、高级感」等抽象结论；每条都落到物件、光位、比例或数值
- 不在 S0 询问模型、不给提示词
- 不把长时长上限当成拉长镜头；成片镜头按用户给定的单镜区间（建议 2–4 秒，可改）
- 原片画面与引用的第三方提示词不可直接商用

- **色卡使用边界（v4.1）**：A08 交付的是把 12 个 HEX 写死的**成品出图提示词**（纯文字出图、不传参考图；「12 色归纳」中文只是生成它的 meta 指令），生成的 `COLOR_CARD_01` **在 A 段场景图（取色彩方案）与 C 段视频【参考绑定】两处使用**；A 段场景图同传色卡取色彩方案；A00 母版 / 标准首帧 / 人物资产不挂色卡，全阶段不写 `--sref`。
- **场景与反打边界（v4.1）**：A01–A0N 恒为「一条通用正文 + N 条场景句组件表」，占比等验收口径不进提示词代码块；`SCENE_REVERSE_0X` 是**可选**资产，由用户自行选择用不用，不用时删 C 段引用、首帧第 2 张参考换 `SCENE_MOOD_01`。
- **摄影母版（v4.3）**：`PHOTO_MASTER_01` 中文文字块，为**一段连续专业摄影描述**（只写跨镜头统一项、不含具体焦段；焦段与 T 光圈下放到逐镜块），不生成图片、不上传，C 段逐字复用。
- **视频提示词结构（v3.8）**：【视频基本参数】【参考绑定】【摄影母版】【禁止项】【画面描述】【收束与音频】六块齐全。
