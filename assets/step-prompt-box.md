# 粘贴框规范（v5.0 建立 / v5.4 纯净口径 · 唯一权威）

> 用户 2026-11-08 二次纠偏：「**不要把一次生成的所有提示词放在一个复制框内，每个单独的提示词用单独的复制框**」。本文件规定怎么给这些框。

## 1. 一条提示词 = 一个框

每一条提示词单独占一个 fenced code block，**一次只复制这一条**。禁止把多条提示词塞进同一个框，也禁止用 `=== 第 N 条 ===` 之类的分隔行在一个框里拼接。

## 2. 框上面一行写清这是什么

每个框**上方**（框外）写一行：

**第 N 条：用途 | 模型 | 产出文件名**

例如：`**第 1 条：色卡 | Nano Banana Pro | 色卡.png**`。这样用户不用猜这一框是干嘛的、出图该存成什么。

## 3. 框里放什么、不放什么

| 放 | 不放 |
|---|---|
| **这一条**提示词正文（简体中文）、直接告诉 AI 的画面 / 光影 / 动作 / 声音 / 参考图怎么用 | 其它提示词、解释、为什么这么写 |
| A 段出图提示词末尾的「画幅 16:9。」 | **C 段视频提示词里**的模型名 / 平台名 / 档位 / 生成条编号 / 成片时间码 / 分辨率 / 帧率 / 挑片 / 记录种子 / 剪辑台衔接 / 跨步骤说明 / 按需补图（**v5.4 一律不进代码块**，见 `references/prompt-examples-video.md` §8.8） |
| 资产 ID / 器材型号 / 单位与色值 | 上传顺序、传几张图、验收口径、占比、元指令、跨步骤规则声明 |

框**外**用一句话给用法：去哪个平台 → 传什么 → 粘第几条 → 选几秒档 → 生成几次 → 怎么挑。

## 4. 两处逐字一致

对话框的每个框是**准本**；本地 `第N步_*.md` 第 4 节按同样顺序放同样数量的独立代码块，**一条对一个、逐字一致**。改了一处就要同步另一处。

## 5. 哪些步没有框

0 准备 / 1 视频总规划 / 3 视频分镜设计及脚本 / 6 自查 —— 这几步只给表格与清单，不硬造提示词，所以没有粘贴框。

## 6. 与既有硬口径的关系

本规范只管**怎么装框**，不改框里任何一个字：固定风格、色卡两处使用、一段式摄影母版、视频六块结构、全局段 + 逐镜块、人物两类成对、固定画质段、v5.4 提示词纯净原则全部照旧；【视频基本参数】只写视频时长 / 视频比例 / 视频类型 / 视频概述四类。`autopilot` 交接包不走粘贴框，按 `libtv-handoff-template.md` 逐字打包。
