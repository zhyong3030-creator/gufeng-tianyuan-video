**两步走**：① 用「12 色归纳 meta 指令」对**参考素材**（参考片画面帧优先；无帧才用视觉母版 + 场景基调图）做实际归纳，先并排做分组检查，色温 / 色相明显分两组就提醒用户重新分组、不强行合并；得出 4 主 / 4 辅 / 2 强调 / 1 高光 / 1 阴影共 12 个 HEX 与主要用途，再加一句冷暖 / 饱和 / 明暗概括。② 把结果写死成下面这条**纯文字出图提示词**，**不上传任何参考图**。

🟦 **提示词（成品模板，整段复制；把 `[...]` 换成实测归纳结果）** ｜ 模型：中文小字能力稳的图像模型 ｜ 产出 `COLOR_CARD_01.png` ｜ 使用 ✅ **A 段场景图取色彩方案 + C 段视频生成条**

```
请生成一张简洁的平面色卡：纯色矩形色块，无渐变、无纹理、无投影、无立体效果，色块之间留细窄白边，背景为中性浅灰，色块面积均等。

第三行 2 个强调色：[#XXXXXX 用途]、[#XXXXXX 用途]；
```

> ⚠️ 用户给的那段「请分析这些参考图共同的色彩规律…」是**生成提示词的提示词**，只指导归纳，**不要写进 A08 交付物、也不要复制到平台**。色卡只给 HEX 与用途，**不负责面积占比**；65 / 20 / 12、九宫格与五级明度由色场方案表与 `PHOTO_MASTER_01`【光影色彩】写死。有参考帧时色卡可在 `A00` 之前独立完成，**且必须先于 A01**；生成后先给场景图取色彩方案（§15.4 / §15.5），再到 C 段【参考绑定】上传。

## 15.2 `PHOTO_MASTER_01` · 摄影母版（v4.3 一段式文字块，不上传）

把 S0「光影特点 / 摄影设定」两节固化成一份中文文字块；**不生成图片、不占参考位**，C 段每条逐字复用。**v4.3 起为一段连续专业摄影描述，不再分三个子标签**：只写跨镜头统一项，不写具体焦段与光圈（下放到逐镜块），并承载「高光不漂、暗部留色相」的色彩体积原则。

```
统一使用数字电影摄影机与定焦镜头组，24fps，180 度快门，ISO 800，画幅 [16:9]、成片 [1080p]；真实电影摄影质感，自然运动模糊，柔和高光滚降，宽容度充足。画面保持高色彩密度与明确主色控制，中间调留住 [主色名] 的综合色彩，高光为奶油金并柔化扩散但不漂白，暗部抬高仍压住 [辅色名] 且保留木纹、织纹、砖缝与陶土颗粒，让暖调有胶片般的色彩体积，不出现数码荧光与廉价高饱和感。肤色恒为暖象牙到蜜桃，与暖绯环境清晰分离，保留真实毛孔与细绒，不磨皮、不过度锐化。天芬 Black Pro-Mist 1/8 低密度黑柔滤镜，柔光与光晕全片统一加一次，不逐镜叠加。机身眼平、全程静态，靠画面内遮挡与剪辑换景。颜色可以很淡，但高光不能漂，暗部也必须保留色相，这样统一色场才有体积。
```

## 15.3 C 段视频提示词 · 六块结构

每条生成条整段复制：**【视频基本参数】→【参考绑定】→【摄影母版】→【禁止项】→【画面描述】→【收束与音频】**。

| 块 | 要点 |
|---|---|
| 视频基本参数 | 模型 / 档位 / 生成条编号 / 时长 / 成片时间码 / 画幅 / 帧率 / 首帧 / beat 与切点数 / 生成次数与记录项 |
| 参考绑定 | 逐张写继承 / 不继承；**色卡第二处使用**（第一处在 A 段场景图取色彩方案）；人物只挂 `@ROLE_SHEET_X` + `@FACE_CLOSE_X` 两类成对 |
| 摄影母版 | §15.2 全文逐字粘贴（一段式、不含焦段），条间不许改写 |
| 禁止项 | 块名叫「禁止项」，**内部一律写正向句** |
| 画面描述 | 全局设定段（统一场景 / 占比 / 光位 / 动作 / 切镜规则）+ `【镜头N | 时间码 | 镜头名】` 逐镜块；每镜写三层空间 / 景别 / 机位高度+焦段+光圈 / 占画面比 / 动作 / 运镜 / 焦点 / 环境动态 / 切点匹配；不跨块重复 |
| 收束与音频 | 收束留白与环境声；不复述人物一致性 |

完整模板与上传顺序见 `references/prompt-examples-video.md` §8。
