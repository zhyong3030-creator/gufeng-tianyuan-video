# 《[主题]》· 影像总揽

## 一、一句话内核

用一句**可见动作**说明这支片子拍什么，不写情绪词、不写「东方美学 / 电影感 / 高级感」。
例：`雪夜药铺里，学徒把一剂药从秤盘装进纸包。`

## 三、整体基调

- 节奏：[静态机位为主、靠剪辑换景、单镜按上表用户给定区间（建议 2–4 秒，可改）、无大起大落运镜]
- 运动量：[每镜只一个可见动作；相邻镜头动作不叠加]
- 声音：[环境声 + 一段克制配乐；无对白、无口播、无字幕朗读]
- 情绪曲线：静 → 缓 → 密 → 扬 → 收（用可见事件表达，不用形容词）

## 六、光影特点

- **主光**：高位斜后侧光，位于摄影机反方向约 120–150°（画面上可左上或右上，但相对人物角度恒定）。
- **补光**：正面仅弱暖反射补光，不打平。
- **轮廓光**：金色/烛金落在发丝、袖缘、器物边缘与水面/雪面反光。
- **肤色**：恒为暖象牙—蜜桃，主色再冷也不把皮肤染成冷灰。
- **暗部**：黑位抬高，保留织纹、木纹、砖缝；阴影带蓝绿或棕褐。
- **高光**：奶油金而非纯白；仅水珠、金属、烛火小面积溢出并柔化扩散。
- **质感**：柔焦、轻微光晕、大而软的散景；不是硬锐数字质感。

## v3.8 · 「光影特点 / 摄影设定」两节的额外用途

这两节不只是总揽说明，它们要在 S3 被固化成 **`PHOTO_MASTER_01` 摄影母版文字块**：v4.3 起为**一段连续专业摄影描述**，只写跨镜头统一不变的机身与镜头组、帧率 / 快门 / ISO、整体质感、色彩密度与主色控制原则、肤色分离、不磨皮不锐化，**不写具体焦段与光圈**（下放到【画面描述】逐镜块）；写进 `提示词全集.md` A 段，**不生成图片、不上传**，C 段每条视频提示词逐字复用同一份。因此本模板里这两节的每一项都必须落到可见的**机身参数、滤镜型号、光位角度、比例、色值或占比**，不能只写「电影感 / 高级感」——否则摄影母版会退化成空话，三条生成条的质感必然漂移。

色卡相关：本阶段只定主辅色占比、九宫格覆盖与五级明度；**A08 是成品色卡出图提示词**（12 个 HEX 写死、纯文字出图），有参考片帧时可独立归纳、在 `A00` 之前完成，**且供 A 段场景图（取色彩方案）与 C 段视频两处使用**，不在 S0 出现具体 `COLOR_CARD_01` 引用。另：A01–A0N 场景提示词为「一条通用正文 + N 条场景句」，场景反打由用户在 S3 自行选择用不用。见 `references/color-system.md` §7 与 `SKILL.md` 第 20 / 21 条。
